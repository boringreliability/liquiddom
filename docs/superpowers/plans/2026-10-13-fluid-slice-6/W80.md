**Goal:** a per-instance scroll tracker in TypeScript and one new scalar FFI call in Rust (`scroll_shift`) that moves the liquid rigidly with the page instead of letting the moved rects excite it, plus light inertia, a mid-drag correction and container scroll, so step 7 works in both renderers.

**Architecture:** `ScrollTracker` (new `scroll-tracker.ts`, one per instance) reads the window's `scrollX/scrollY` (body mode) or the container's `scrollLeft/scrollTop` once per frame, right after `applyDomChanges()`, and returns the delta since the last frame (0 on an instance's first frame), the inertia `Δ · 60 · SCROLL_INERTIA` capped at `SCROLL_INERTIA_MAX_PX_S` (0 under reduced motion or on a frame without elapsed time) and the delta a live press adds to its drag offset. In container mode `placeCanvas()` keeps liquiddom's canvas on the container's visible window with a `transform` on the canvas only. The runtime then calls `dragTracker.scrolled()` (the dragged liquid stays under the pointer), `dragTracker.frame()`, `registry.sync()` (this frame's rects) and, only when something scrolled, `core.scroll_shift(dx, dy, ivx, ivy)` before `core.tick()`. Rust (`src/fluid/scroll.rs`): `ScrollShift::sanitized` (NaN/Inf → 0, shift clamped to ±`WORLD_MAX_PX`, inertia capped at 2000 px/s, 0 under reduced motion); `scroll::apply` splits the delta into whole cells (the particles move by them) and a sub-cell rest (the grid's lattice origin moves by it, `Grid::scroll_origin`, kept within half a cell of `−margin`), so every particle of an element that `shifts_with_scroll` (not dragged; W81 adds "not parked") moves by exactly `(−dx, −dy)` px while keeping its lattice phase, gains the inertia, and its element's previous home rect moves with it (`Elements::shift_prev`), so `update_velocities` sees no motion. `invalidate_bounds()` as for splash (D68-10).

**Design resolutions this plan makes (stated in the D80 Proposal texts so the gate covers them):**
1. **Whole cells plus a lattice-origin rest, not a plain shift** (D80-1). MLS-MPM's quadratic B-spline transfers are translation-invariant only by whole cells. This plan's validation measured a plain shift by `Δ/cell` (cell 6.17 px) diverging from an unscrolled core by **5.05 px** within 60 frames of a splash in flight (0.17–0.27 px after the first frame); with the particles moved by whole cells and the grid origin by the rest, the divergence is **≤ 0.0031 px** over 600 frames at 1 px/frame, 0.0009 px at 10 px/frame and 0.0003 px for a 300 px jump. The origin stays within half a cell of `−margin`, so the walls move by ≤ 3.1 px.
2. **"Bit-identical" becomes "identical up to f32 rounding"** (D80-1). Rewriting positions in f32 cannot be bit-exact; the tests bound it at 0.01 px. A zero shift is a bit-exact no-op, and an idle page never calls `scroll_shift` (the runtime skips frames without a scroll), so every run without a scroll stays bit-identical to W79.
3. **A dragged element is not shifted** (D80-1). TS adds the scroll to the drag offset in the same frame, so the dragged home (rect + offset) stays put in the viewport; Rust leaves its particles in place (they move by the origin's rest in grid units) and its previous rect unshifted, so its home velocity (rect delta + offset delta, W78) is 0. A scroll during a press below the threshold accumulates into the offset, but only the pointer's own motion crosses the threshold. In container mode a page scroll around the container also moves the pointer relative to the element in buffer space (`dragDx = Δscroll − Δoffset`).
4. **The inertia is per distance, not per Δ/dt** (D80-2). The design text says `Δ / frameDt · SCROLL_INERTIA`; Rust adds `iv` once per call, so that form doubles a scroll's total impulse at 120 Hz (the D68-4 limitation). `Δ · 60 · SCROLL_INERTIA` equals it at 60 Hz and is frame-rate independent. A frame without elapsed time (the first after a pause or a hidden tab) shifts the whole delta with no inertia.
5. **A canvas remount does not reset the tracker** (D80-1). The slice design lists "a remount" among the zero-delta cases; the core keeps its particles across a remount (D72-3), so a dropped delta would leave the liquid where the content was — the snap step 7 forbids. Only a new instance (and `reset()`, unused by the runtime) starts at 0; a remounted container canvas gets the transform on its first frame.
6. **The acceptance scene's spacer leaves every baseline where it is** (D80-3). Linux baselines are viewport screenshots at scroll 0 and Playwright's headless Chromium runs with `--hide-scrollbars`, so a taller document changes no pixel; W80.4 checks that the eleven existing baselines do not move. The "scrolled back" check reuses `acceptance-step1.png`.

### D80-1: Scroll model — rigid scroll_shift in viewport space, whole cells plus a lattice-origin rest
Proposal: buffer space stays the viewport (body mode) or the container's visible window (container mode). `scroll-tracker.ts` (one per instance) reads the window's `scrollX/scrollY` or the container's `scrollLeft/scrollTop` once per frame after `applyDomChanges()`; Δ = now − previous (an instance's first frame 0; a non-finite read gives 0 and keeps the last good position; a canvas remount does not reset it; a frame resumed after a pause shifts the whole Δ). After `registry.sync()` and before `tick` the runtime calls `core.scroll_shift(dx, dy, ivx, ivy)`, only on frames with a scroll. Rust moves every particle of an element that moves with the page by whole cells and the grid's lattice origin by the sub-cell rest (`Grid::scroll_origin`, the origin kept within half a cell of `−margin`), so the particles keep their lattice phase and move by exactly (−dx, −dy) px; that element's previous home rect moves with it, so its home velocity is 0 and nothing un-rests. A dragged element is not shifted (its particles stay put in px); TS adds the scroll to its drag offset in the same frame (a press below the 4 px threshold accumulates it, but a scroll alone never starts a drag), so the dragged liquid stays under the pointer; in container mode a page scroll around the container counts for the drag too (`dragDx = Δscroll − Δoffset`) and shifts nothing else. Container mode: `transform: translate(scrollLeft, scrollTop)` on liquiddom's canvas keeps it on the container's visible window (written only on change, re-applied to a remounted canvas; never on author DOM). Sanitised in Rust: NaN/Inf → 0, shift clamped to ±`WORLD_MAX_PX` (a negative one, overscroll, is kept), inertia capped at 2000 px/s; `invalidate_bounds()` (D68-10). Reduced motion: the shift applies, the inertia is 0 (TS and Rust). No parking (W81). Chosen in the brainstorm (Dennis 2026-10-13, saga dec_645b54e4); the lattice-origin split, the drag rules, the remount rule and the container rules are the plan's resolutions.
Consequence: the spec's "without inertia the simulation is bit-identical to an unscrolled page" becomes "identical up to f32 rounding" (positions rewritten in f32 cannot be bit-exact; the plan validation measured ≤ 0.0031 px over 300 px down and back, also with a splash in flight, where a plain shift by fractions of a cell diverged by 5.05 px within 60 frames). A zero shift is a bit-exact no-op and an idle page never calls `scroll_shift`, so runs without a scroll stay bit-identical to W79. The grid's walls move by up to half a cell (≤ 4 px). Elements scrolled beyond the 200 px grid margin clamp to the walls until W81 parks them. One new scalar FFI call, no new slot.
Decision: PENDING

### D80-2: Inertia — Δ · 60 · SCROLL_INERTIA, capped (values from W80.0)
Proposal: `iv = Δ · 60 · SCROLL_INERTIA` px/s (equal to the design's `Δ / frameDt · SCROLL_INERTIA` at 60 Hz) with the direction of the scroll (down → ivy > 0 → the liquid lags below its home), its speed capped at `SCROLL_INERTIA_MAX_PX_S`; 0 on a frame without elapsed time (the first after a pause or a hidden tab) and under reduced motion. Rust adds it to the shifted particles' velocities. Values from the spike; the plan carries provisional `SCROLL_INERTIA` 0.05 and `SCROLL_INERTIA_MAX_PX_S` 120 (plan validation, Rust, 10 px/frame: the card lags ≤ 5.9 px, worst maxDev 7.06 px, every restAlpha 1 26 frames after the scroll back).
Consequence: per distance, not per Δ/dt: the design's form doubles a scroll's total impulse at 120 Hz (Rust adds `iv` once per call; the D68-4 limitation); this one is the same at any frame rate. A fast scroll un-rests the elements for a moment (Canvas2D draws the density instead of the exact rect, WebGPU the liquid text) and they settle within the budget; a slow one stays at rest while its lag is under 0.75 px. `FILL_MIN` (D80-3) follows from these values.
Decision: PENDING

### D80-3: Step-7 budget and "no snap"
Proposal: NORTH-STAR step 7 and spec §6 step 7 change together to `7. Scroll 300 px and back: the liquid follows with no snap and every element is at rest within **3 s** after the scroll.` (seconds from the spike; the recommended 3 s matches steps 3, 5 and 6), so `e2e/north-star.ts` gives a step-7 budget. "No snap" is measured per frame as the fill of every visible element's DOM shape (its rounded rect inset 4 px) by its own colour or by liquid text, ≥ `FILL_MIN` (provisional 0.75; the gate sets min(0.9, the spike's lowest browser fill − 0.05)), at 1, 10 and 300 px per frame, during a smooth `scrollTo`, mid-drag and in a container. Consequence: step 7 carries a number the e2e, the whole picture (W87) and the recording read. A fill bound is a proxy: a liquid that trails by less than a few px passes it; the vision check at gold covers what it cannot see. If the spike shows a re-form above 3 s at 300 px per frame, this gate decides between a larger budget and lower inertia.
Decision: PENDING

### D80-4: The 1-frame lag behind native scroll
Proposal: the canvas is `fixed` (body mode) and redrawn in RAF, so during a compositor (wheel, touch) scroll the liquid can trail the DOM by one frame. Accepted if the spike shows it invisible at rest: at rest Canvas2D draws the exact rect and WebGPU the rest SDF, and the DOM text never lags. Evidence: RAF-clock recordings of a 300 px wheel scroll and a smooth `scrollTo` in Chromium headless (Canvas2D) and on Metal (WebGPU), inspected frame by frame with vision, plus a logged, never-gated probe in `webgpu-hw` (canvas card edge minus DOM card edge per screenshot, `w80-lag-webgpu.json`). If it is visible at rest: STOP and re-plan "a canvas that scrolls with the content" as a new decision before red.
Consequence: a trailing frame during a fast native scroll stays a known, documented limitation (spec §4, CONTEXT). The probe is diagnostic: screenshots and DOM reads are not in one atomic frame, so it reports an uncertainty with each sample.
Decision: PENDING

//! W80: scroll follows (slice-6 design §3; spec §2 interaction table, scroll row; D80-1, D80-2).
//!
//! Unit tests drive `ScrollShift` and `Grid::scroll_origin`; scenario tests drive the real
//! `FluidCore` over the acceptance layout (`scenario_tests`: three buttons 140×48 r24 at y 260,
//! card 320×180 r16 at y 340, 1280×800, seed 1). A page scrolled by `S` px is driven the way TS
//! drives it: every rect is written `S` px higher, then `scroll_shift(0, Δ, …)` runs before the
//! tick.

use super::api::FluidCore;
use super::grid::{Grid, WORLD_MAX_PX};
use super::layout::INTERACTION_DRAGGED;
use super::scenario_tests::{AREA_HINT_PX2, LAYOUT, SEED, acceptance_core, slot};
use super::scroll::{SCROLL_INERTIA_VMAX_PX_S, ScrollShift};

const DT: f32 = 1.0 / 60.0;
/// NORTH-STAR step 7: 300 px down and back.
const SCROLL_PX: f32 = 300.0;
/// The middle speed of the W80.0 matrix: 10 px per frame.
const STEP_PX: f32 = 10.0;
/// Provisional TS constants (`scroll-tracker.ts`), replaced at the gate from W80.0 (D80-2):
/// inertia = Δ · 60 · SCROLL_INERTIA px/s, capped at SCROLL_INERTIA_MAX_PX_S.
const SCROLL_INERTIA: f32 = 0.05;
const SCROLL_INERTIA_MAX_PX_S: f32 = 120.0;
/// Provisional step-7 budget (D80-3): 3 s at 60 Hz.
const STEP7_BUDGET_FRAMES: u32 = 180;
/// The plan validation measured 7.06 px; bound = 1.5 × that, rounded up (D80-2 consequence).
const INERTIA_MAX_DEV_PX: f32 = 11.0;
/// f32 rounding of the shifted positions (the plan validation measured ≤ 0.0031 px).
const ROUNDING_PX: f32 = 0.01;
const MERGE_ID: usize = 2;
const CARD_ID: usize = 3;

fn frame(core: &mut FluidCore) -> u32 {
    core.tick(DT, 0.0, 0.0, 0.0, 0.0, false, 0.0, 0.0)
}

/// Writes every acceptance rect `scroll_y` px higher (the page scrolled down by `scroll_y`).
fn write_scrolled(core: &mut FluidCore, scroll_y: f32) {
    for (id, e) in LAYOUT.iter().enumerate() {
        let mut r = *e;
        r[1] -= scroll_y;
        core.write_element(id, slot(r));
    }
}

/// TS's inertia for a frame's scroll delta (provisional D80-2 constants, `scroll-tracker.ts`).
fn inertia(delta: f32) -> f32 {
    (delta * 60.0 * SCROLL_INERTIA).clamp(-SCROLL_INERTIA_MAX_PX_S, SCROLL_INERTIA_MAX_PX_S)
}

/// One frame of a page scrolled from `from` to `to` px: rects, shift, tick.
fn scroll_frame(core: &mut FluidCore, from: f32, to: f32, with_inertia: bool) {
    write_scrolled(core, to);
    let d = to - from;
    let iv = if with_inertia { inertia(d) } else { 0.0 };
    core.scroll_shift(0.0, d, 0.0, iv);
    frame(core);
}

/// Step 7's scroll positions at `step` px per frame: down to SCROLL_PX, then back to 0.
fn step7_path(step: f32) -> Vec<f32> {
    let n = (SCROLL_PX / step).round() as usize;
    let down = (1..=n).map(|k| k as f32 * step);
    let back = (0..n).rev().map(|k| k as f32 * step);
    down.chain(back).collect()
}

fn homed(core: &FluidCore) -> Vec<usize> {
    (0..core.particle_capacity() as usize)
        .filter(|&i| core.target_px(i).is_some())
        .collect()
}

fn all_at_rest(core: &FluidCore) -> bool {
    core.rest_alphas().iter().all(|&a| a >= 1.0)
}

/**
 * W80 (D80-1 … D80-4): step 7 helpers. A scroll runs on the manual clock, one frame per position:
 * the page (or the container) is scrolled with `behavior: "instant"`, one frame runs, and the frame's
 * canvas snapshot (`pixels()`, W71 rule) is read against the DOM rects of that same moment.
 *
 * "Follows with no snap" is measured as the fill of each element's visible DOM shape (its rounded
 * rect inset by FILL_INSET_PX, clipped to the canvas) by its own colour or by liquid text (near
 * white): a liquid left behind by a scroll, or one that jumps after it, empties the shape. The
 * canvas is mapped through its own client rect, so a container canvas that is not on the
 * container's visible window (W80's transform) fails the fill as well.
 */
import type { Page } from "@playwright/test";

/** The acceptance scene's element colours (demo/scenes/acceptance.html). */
export const W80_COLOURS: Readonly<Record<string, readonly [number, number, number]>> = {
  "#splash": [0x2f, 0x6f, 0xde],
  "#split": [0xca, 0x4b, 0x20],
  "#merge": [0x1a, 0x83, 0x61],
  "#card": [0x26, 0x32, 0x38],
};
/** px inside the DOM shape that must be filled (the density edge is soft over a few px). */
export const FILL_INSET_PX = 4;
/** An element is judged only while at least this many px of its inset shape are visible. */
export const FILL_MIN_VISIBLE_PX = 8;
/**
 * D80-2 consequence (provisional, from the plan validation's inertia lag of ≤ 7.1 px on a 40 px inner
 * pill height): the lowest fill a frame may show. W80.0 measures the real minimum per speed; the
 * gate sets this to min(0.9, measured − 0.05).
 */
export const FILL_MIN = 0.75;

export interface FillFrame {
  /** The scroll position this frame ran at (px), read after the scroll. */
  scroll: number;
  /** The lowest fill over the judged elements (1 when none was visible). */
  min: number;
  /** Selector of that element ("" when none was judged). */
  worst: string;
}

export interface FillSpec {
  /** "__liquidTest" (acceptance scene) or "__scrollContainer" (W80 container scene). */
  hook: "__liquidTest" | "__scrollContainer";
  /** CSS selector of the liquid canvas whose client rect maps the snapshot. */
  canvas: string;
  /** null: the window scrolls; else the selector of the scrolled container. */
  scroller: string | null;
  colours: Readonly<Record<string, readonly [number, number, number]>>;
}

export const ACCEPTANCE_FILL: FillSpec = { hook: "__liquidTest", canvas: "canvas.liquid-canvas", scroller: null, colours: W80_COLOURS };

/**
 * Runs one frame per entry of `path` (inside the page, in one task per frame; `null` runs the frame
 * without scrolling, e.g. while a smooth scroll animates) and returns each frame's lowest fill. The fill of one element: pixels of its rounded DOM rect inset by
 * FILL_INSET_PX with alpha > 128 and either |rgb − colour|₁ < 60 or every channel ≥ 200 (liquid
 * text), over all pixels of that inset shape inside the canvas.
 */
export async function scrollPathFills(page: Page, spec: FillSpec, path: readonly (number | null)[]): Promise<FillFrame[]> {
  return page.evaluate(
    ([s, positions, inset, minVisible]) => {
      type Hook = { advance(n: number): void; pixels(): ImageData };
      const hook = (window as unknown as Record<string, Hook>)[s.hook];
      const scroller = s.scroller === null ? null : document.querySelector<HTMLElement>(s.scroller);
      const out: Array<{ scroll: number; min: number; worst: string }> = [];
      for (const y of positions) {
        if (y !== null && scroller) scroller.scrollTo({ top: y, behavior: "instant" });
        else if (y !== null) window.scrollTo({ top: y, behavior: "instant" });
        hook.advance(1);
        const at = scroller ? scroller.scrollTop : window.scrollY;
        const img = hook.pixels();
        const canvas = document.querySelector<HTMLCanvasElement>(s.canvas)!;
        const cr = canvas.getBoundingClientRect();
        const kx = img.width / cr.width;
        const ky = img.height / cr.height;
        let min = 1;
        let worst = "";
        for (const [sel, [cr0, cg0, cb0]] of Object.entries(s.colours)) {
          const el = document.querySelector<HTMLElement>(sel)!;
          const r = el.getBoundingClientRect();
          const rad = Math.max(0, parseFloat(getComputedStyle(el).borderTopLeftRadius) - inset);
          const x0 = r.left + inset;
          const y0 = r.top + inset;
          const x1 = r.right - inset;
          const y1 = r.bottom - inset;
          const vx0 = Math.max(x0, cr.left);
          const vy0 = Math.max(y0, cr.top);
          const vx1 = Math.min(x1, cr.right);
          const vy1 = Math.min(y1, cr.bottom);
          if (vx1 - vx0 < minVisible || vy1 - vy0 < minVisible) continue;
          let inside = 0;
          let filled = 0;
          for (let py = Math.ceil(vy0); py < vy1; py++) {
            for (let px = Math.ceil(vx0); px < vx1; px++) {
              // Inside the rounded rect inset by `inset` (corner radius shrinks with it).
              const cx = Math.min(Math.max(px + 0.5, x0 + rad), x1 - rad);
              const cy = Math.min(Math.max(py + 0.5, y0 + rad), y1 - rad);
              if ((px + 0.5 - cx) ** 2 + (py + 0.5 - cy) ** 2 > rad * rad) continue;
              inside++;
              const ix = Math.floor((px - cr.left) * kx);
              const iy = Math.floor((py - cr.top) * ky);
              const o = (iy * img.width + ix) * 4;
              const d = img.data;
              if (d[o + 3] <= 128) continue;
              const colour = Math.abs(d[o] - cr0) + Math.abs(d[o + 1] - cg0) + Math.abs(d[o + 2] - cb0) < 60;
              const text = d[o] >= 200 && d[o + 1] >= 200 && d[o + 2] >= 200;
              if (colour || text) filled++;
            }
          }
          const fill = inside > 0 ? filled / inside : 1;
          if (fill < min) {
            min = fill;
            worst = sel;
          }
        }
        out.push({ scroll: at, min, worst });
      }
      return out;
    },
    [spec, path, FILL_INSET_PX, FILL_MIN_VISIBLE_PX] as const,
  );
}

/** Step 7's scroll positions at `step` px per frame: down to `distance`, then back to 0. */
export function scrollPath(distance: number, step: number): number[] {
  const n = Math.round(distance / step);
  const down = Array.from({ length: n }, (_, k) => (k + 1) * step);
  const back = Array.from({ length: n }, (_, k) => (n - 1 - k) * step);
  return [...down, ...back];
}

/** The frame with the lowest fill of a run. */
export function worstFrame(frames: readonly FillFrame[]): FillFrame {
  return frames.reduce((w, f) => (f.min < w.min ? f : w), { scroll: Number.NaN, min: 1, worst: "" });
}

// W80 (slice design §11): a scroll frame costs at most 1.15 × the same frame without the scroll.
// Both runs shake first, so both draw the density field: the ratio isolates what the scroll adds
// per frame (the scroll read, the canvas placement, the rect re-layout after scrollTo,
// scroll_shift). The at-rest ratio (scroll vs idle, where the inertia un-rests elements and Canvas2D
// switches from rounded rects to the density) is logged, not gated.
const W80_SCROLL_OVER_IDLE_MAX = 1.15;
const W80_COST_FRAMES = 30;
const W80_COST_RUNS = 3;

/** Median wall ms of `advance(1)` over W80_COST_FRAMES frames, scrolling 10 px per frame or not, after a shake or at rest. */
async function w80FrameMedianMs(page: Page, scroll: boolean, shake: boolean): Promise<number> {
  await w79OpenCostScene(page);
  await page.mouse.move(1279, 799);
  return page.evaluate(
    ([n, withScroll, withShake]) => {
      if (withShake) (window.__liquidTest!.instance as { shake(): void }).shake();
      const out: number[] = [];
      for (let f = 1; f <= n; f++) {
        if (withScroll) window.scrollTo({ top: f * 10, behavior: "instant" });
        const t = performance.now();
        window.__liquidTest!.advance(1);
        out.push(performance.now() - t);
      }
      out.sort((a, b) => a - b);
      return out[Math.floor(out.length / 2)];
    },
    [W80_COST_FRAMES, scroll, shake] as const,
  );
}

    /// W80 (D80-1): a scroll moved the content by `(−dx, −dy)` px. Splits each delta into whole
    /// cells `k` (the caller moves the particles by `−k` grid units) and a rest `f` px (the lattice
    /// origin moves by `−f` here), so `k·cell + f = d` and the particles keep their phase on the
    /// lattice: MLS-MPM's quadratic B-spline transfers are translation-invariant only by whole
    /// cells, so a shift by a fraction of a cell would change the motion of liquid in flight. `k`
    /// is chosen so the origin stays within half a cell of `base_origin_px` (the walls move by at
    /// most that much). Returns `(kx, ky)` in cells. A non-finite delta moves nothing.
    pub fn scroll_origin(&mut self, dx_px: f32, dy_px: f32) -> (f32, f32) {
        let split = |d: f32, origin: f32| -> (f32, f32) {
            if !d.is_finite() {
                return (0.0, 0.0);
            }
            let drift = origin - self.base_origin_px;
            let k = ((d - drift) * self.inv_cell).round();
            (k, d - k * self.cell_px)
        };
        let (kx, fx) = split(dx_px, self.origin_x_px);
        let (ky, fy) = split(dy_px, self.origin_y_px);
        self.origin_x_px -= fx;
        self.origin_y_px -= fy;
        (kx, ky)
    }

//! W80 (D80-1, slice-6 design §3): scroll follows. Buffer space stays the viewport; TS reads the
//! scroll delta once per frame and calls `FluidCore::scroll_shift(dx, dy, ivx, ivy)` after
//! `registry.sync()` and before `tick`. The shift moves every particle of an element that moves
//! with the page, and that element's previous home rect, by `(−dx, −dy)` px, so the rect velocity
//! (`update_velocities`) sees only motion beyond the scroll and a scroll does not excite the
//! liquid. The particles move by whole cells and the grid's lattice origin by the rest
//! (`Grid::scroll_origin`), so they keep their lattice phase and the simulation equals the
//! unscrolled one up to f32 rounding, at rest and in flight. A light inertia `(ivx, ivy)` px/s
//! is added to the shifted particles' velocities: scrolling down (dy > 0) moves the content up,
//! the liquid lags below its home (ivy > 0, viewport space) and the home spring brings it back.
//!
//! A dragged element is skipped: its home is pinned to the pointer (TS adds the scroll delta to
//! its drag offset in the same frame), so its liquid stays where it is in the viewport. W81 adds
//! parked elements to the skip (`shifts_with_scroll`).

/// it far lower (`SCROLL_INERTIA_MAX_PX_S`, D80-2); this only keeps a hostile value bounded.
pub const SCROLL_INERTIA_VMAX_PX_S: f32 = POINTER_VMAX_PX_S;

/// One frame's scroll, sanitised (`ScrollShift::sanitized`).
#[derive(Clone, Copy, Debug, PartialEq)]
pub struct ScrollShift {
    /// Scroll delta in px (the content moved by `(−dx, −dy)` in the viewport).
    pub dx_px: f32,
    pub dy_px: f32,
    /// Inertia added to the shifted particles' velocities, px/s.
    pub ivx_px_s: f32,
    pub ivy_px_s: f32,
}

impl ScrollShift {
    /// No scroll.
    pub const NONE: ScrollShift = ScrollShift {
        dx_px: 0.0,
        dy_px: 0.0,
        ivx_px_s: 0.0,
        ivy_px_s: 0.0,
    };

    /// Last-line defence for the FFI scroll (TS validates first): a non-finite delta is 0 and a
    /// finite one is clamped to ±`WORLD_MAX_PX` per axis (a negative one, e.g. overscroll, is
    /// kept); a non-finite inertia (either axis) is 0 and its speed is capped at
    /// `SCROLL_INERTIA_VMAX_PX_S` with the direction kept, also when `|v|` overflows f32;
    /// reduced motion drops the inertia (D80-1).
    pub fn sanitized(dx: f32, dy: f32, ivx: f32, ivy: f32, reduced_motion: bool) -> ScrollShift {
        let shift = |v: f32| finite_or(v, 0.0).clamp(-WORLD_MAX_PX, WORLD_MAX_PX);
        let (ivx_px_s, ivy_px_s) = if reduced_motion || !(ivx.is_finite() && ivy.is_finite()) {
            (0.0, 0.0)
        } else {
            let speed = ivx.hypot(ivy);
            if speed <= SCROLL_INERTIA_VMAX_PX_S {
                (ivx, ivy)
            } else if speed.is_finite() {
                let k = SCROLL_INERTIA_VMAX_PX_S / speed;
                (ivx * k, ivy * k)
            } else {
                // Both axes finite but |v| overflows f32: normalise by the larger axis first.
                let m = ivx.abs().max(ivy.abs());
                let (ux, uy) = (ivx / m, ivy / m);
                let k = SCROLL_INERTIA_VMAX_PX_S / ux.hypot(uy);
                (ux * k, uy * k)
            }
        };
        ScrollShift {
            dx_px: shift(dx),
            dy_px: shift(dy),
            ivx_px_s,
            ivy_px_s,
        }
    }

    /// True when the shift moves nothing and adds no velocity.
    pub fn is_none(&self) -> bool {
        self.dx_px == 0.0 && self.dy_px == 0.0 && self.ivx_px_s == 0.0 && self.ivy_px_s == 0.0
    }
}

/// W80 (D80-1): whether element `id`'s particles and previous home rect follow the scroll. A
/// dragged element does not: its home is pinned to the pointer. W81 also skips a parked element.
pub fn shifts_with_scroll(e: &Elements, id: usize) -> bool {
    !e.is_dragged(id)
}

/// Applies a sanitised shift. The grid's lattice origin moves by the sub-cell rest
/// (`Grid::scroll_origin`) and every homed particle whose element `shifts_with_scroll` by the
/// whole cells (clamped to the grid like every position write), so together they move by
/// `(−dx, −dy)` px; those particles gain the inertia. The particles of a dragged element move by
/// the rest in the other direction, so they stay put in px. Each shifted element's previous home
/// rect moves with it. APIC C, J and F are translation-invariant and stay; the grid is cleared
/// every substep; the caller invalidates the fused AABB (D68-10). No allocation, no panic.
pub fn apply(p: &mut Particles, g: &mut Grid, e: &mut Elements, s: &ScrollShift) {
    let moves = s.dx_px != 0.0 || s.dy_px != 0.0;
    let (kx, ky) = if moves {
        g.scroll_origin(s.dx_px, s.dy_px)
    } else {
        (0.0, 0.0)
    };
    // A particle that stays put in px moves by the origin's change in grid units.
    let (rx, ry) = (
        (s.dx_px - kx * g.cell_px) * g.inv_cell,
        (s.dy_px - ky * g.cell_px) * g.inv_cell,
    );
    let (gvx, gvy) = (s.ivx_px_s * g.inv_cell, s.ivy_px_s * g.inv_cell);
    let kicks = gvx != 0.0 || gvy != 0.0;
    for i in 0..p.cap {
        let Some(h) = p.home_of(i) else {
            continue;
        };
        let follows = shifts_with_scroll(e, h);
        if moves {
            let (sx, sy) = if follows { (-kx, -ky) } else { (rx, ry) };
            let (x, y) = g.clamp_pos(rd(&p.x, i) + sx, rd(&p.y, i) + sy);
            wr(&mut p.x, i, x);
            wr(&mut p.y, i, y);
        }
        if kicks && follows {
            add(&mut p.vx, i, gvx);
            add(&mut p.vy, i, gvy);
        }
    }
    if moves {
        for id in 0..e.cap {
            if shifts_with_scroll(e, id) {
                e.shift_prev(id, -s.dx_px, -s.dy_px);
            }
        }
    }
}

 * W80 (D80-1, D80-2; slice-6 design §3): scroll follows.
 *
 * One tracker per instance. Once per frame, right after `applyDomChanges()`, `sample()` reads the
 * scroll position (body mode: the window's `scrollX/scrollY`; container mode: the container's

 * not reset it: the core keeps its particles, and a delta dropped there would be the snap step 7
 * forbids.

/** One frame's scroll. Read it within the frame; the next `sample()` overwrites it. */
export interface ScrollSample {
  /** Scroll delta in CSS px since the previous frame (the content moved by −dx, −dy). */
  readonly dx: number;
  readonly dy: number;
  /** Inertia in px/s for `core.scroll_shift` (0 under reduced motion or without elapsed time). */
  readonly ivx: number;
  readonly ivy: number;

  readonly dragDy: number;

  dy: number;
  ivx: number;
  ivy: number;
  dragDx: number;
  dragDy: number;
}

  private sx = 0;
  private sy = 0;
  private ox = 0;
  private oy = 0;

  private placedX = 0;
  private placedY = 0;

  constructor(

    const o = this.out;
    const sx = this.container ? this.container.scrollLeft : this.win.scrollX;
    const sy = this.container ? this.container.scrollTop : this.win.scrollY;
    const ox = offset.x;
    const oy = offset.y;
    const usable = Number.isFinite(sx) && Number.isFinite(sy) && Number.isFinite(ox) && Number.isFinite(oy);
    if (!usable || !this.hasPrev) {
      o.dx = o.dy = o.ivx = o.ivy = o.dragDx = o.dragDy = 0;
      if (usable) {
        this.hasPrev = true;
        this.sx = sx;
        this.sy = sy;
        this.ox = ox;
        this.oy = oy;
      }
      return o;
    }
    o.dx = sx - this.sx;
    o.dy = sy - this.sy;
    o.dragDx = o.dx - (ox - this.ox);
    o.dragDy = o.dy - (oy - this.oy);

    this.sy = sy;
    this.ox = ox;
    this.oy = oy;

      o.ivx = 0;
      o.ivy = 0;
      return o;

    let ivx = o.dx * REFERENCE_FPS * SCROLL_INERTIA;
    let ivy = o.dy * REFERENCE_FPS * SCROLL_INERTIA;

      ivx *= k;
      ivy *= k;
    }
    o.ivx = ivx;
    o.ivy = ivy;
    return o;
