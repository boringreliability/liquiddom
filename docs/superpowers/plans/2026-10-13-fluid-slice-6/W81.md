**Goal:** elements far off-screen cost nothing and come back at rest; the grid grows once when the window does; the Canvas2D renderer skips liquid that is parked or belongs to a hidden element.

**Architecture:** Rust (`src/fluid/parking.rs`, new) parks and unparks every element at the start of each `tick` (also a 0-step tick) and after `redistribute`, from the rects TS already writes: an element whose home rect lies entirely outside the world plus the grid margin is parked; it comes back once its home rect lies 64 px inside that bound on every side or overlaps the world. Parked particles carry `FLAG_PARKED` (dynamic view `flags` bit 2) and are skipped by the transfers, the particle AABB (so the dirty region shrinks), `scroll::apply` (`shifts_with_scroll` gains "not parked"), splash, shake and the merge damage; the element is held at rest. On re-entry its particles are placed on their targets with their kinematics reset and the element is at rest with no previous rect sample. A parked particle counts as unplaced, so a redistribute that gives it a new home places it on its new target. `FluidCore::resize_world(w, h)` (the one new scalar call) grows the grid arrays and nothing else, keeping the cell, the margin and W80's lattice origin. TypeScript keeps the core's world (`world.ts`, new: body `max(screen, inner)`, container the client box, Rust's clamp mirrored); `resizeCanvas()` grows an outgrown axis to at least 1.25 × its extent and calls `resize_world` from the resize handler with one `console.info`. Canvas2D skips parked particles and an inactive slot's particles; WebGPU packs parked particles off-screen.

**Design resolutions this plan makes (stated in the D81 Proposal texts so the gate covers them):**
1. **Unpark "64 px inside on every side, or overlapping the world"** (D81-1). The slice design says "unparked when it comes ≥ 64 px inside that bound". Read as "its near edge 64 px inside", a tall element unparks with its far part still beyond the wall, where `clamp_pos` piles its particles: they come into view displaced. Read as "the whole rect 64 px inside", a card taller than the margin − 64 px (136 px at the default 200 px margin) would be on screen while still parked. The plan uses the whole-rect reading plus "or it overlaps the world", so a parked element is never on screen and an element up to the margin's height is placed entirely inside the walls. The hysteresis band stays ≥ 64 px (validated: ±5 px jitter at the bound never flaps).
2. **The bound is the grid's world plus its margin, read in Rust** (D81-1). The grid stores `world_w_px`, `world_h_px` and `margin_px` (set in `new` and `resize_world`); the bound is `[−margin, world + margin]` per axis, where the walls sit (up to W80's half-cell drift). No FFI slot, no new constructor argument; Rust stays DOM-blind. In body mode the world is `max(screen, inner)` ≥ the viewport, so "overlaps the world" covers "visible".
3. **Parked particles are unplaced** (D81-1). `pool::redistribute` keeps an already-placed particle's position when it gets a new home (it crawls, W64). A parked particle's position is stale (wherever it was when the element left, often at a wall), so `sync_particles` sets `placed = false` for it; a redistribute then places it on its new target. Validated: a card unobserved while parked hands its particles to a new pill, which starts on target within 0.001 px and at rest.
4. **"Inactive" is read from the element view, not a new particle flag** (D81-1). The slice design says "Canvas2D skips particles whose flags say inactive or parked". An inactive slot (w == 0) is visible to TS already (WebGPU's element record has flags 0 for it), so Canvas2D tests `elementView[id·10 + 2] > 0`; only `PARKED` is a new particle bit. W76 could not reproduce the w == 0 splat because hiding the element itself triggers W75's colour re-read, which rebuilds the paint with area 0; hiding a wrapper does not, and the plan's colour-keyed guard (e2e 31) reproduces it at red (7202 red pixels) and closes it at green (0).
5. **WebGPU skips parked particles in `packParticles`** (D81-1). The splat pass reads no particle flags (they are packed only when the text pass runs), so a parked particle's x, y are packed as `OFFSCREEN_PX`, like a non-finite position; its flags are still packed. A parked element is held at restAlpha 1, so the splat and text passes skip it anyway; the off-screen pack is the second line.
6. **Re-entry happens in `tick`, after `scroll_shift`** (D81-1, Review Focus 1). In the frame an element scrolls in, `scroll_shift` still sees it parked (it is not shifted), then `tick` unparks it and places it on this frame's targets, so it never moves twice; `rest_now` drops its previous rect sample, so its home velocity is 0 and nothing un-rests. An element that scrolls out is shifted one last time (its particles may clamp to a wall) and parked in the same tick.
7. **`resize_world` reallocates the grid arrays only and TS keeps a 1.25 headroom** (D81-2). The origin, the cell and the margin stay, so every particle keeps its grid position and W80's lattice phase; the particle, element, view and scratch buffers are untouched (every pointer TS holds stays valid; Rust test 14 and FFI test 27). TS mirrors Rust's clamp, caps the need at 8192 px, so a world at the cap never calls again, and calls nothing after a failed frame (the core may be poisoned).
8. **No baseline moves, none is added.** The acceptance scene never parks (max scroll 360 px; a pill parks below −200 − 48 px, i.e. after 508 px), and Canvas2D only skips parked or inactive particles, which no baseline shows. W81.4 runs the Docker Canvas2D suite without `--update-snapshots` to prove it. The long page is checked by fills, colour keys and vision.
9. **CONTEXT's stale lock line is already gone.** Spec §4 asks to remove "a large scroll can lock particles … slice-6 parking"; W80's CONTEXT rewrite dropped it (HEAD has no "lock" line). ### D81-1: Parking — not simulated outside world + margin, 64 px hysteresis, re-entry at rest
Proposal: the parking bound is the world the grid covers plus its margin (`max(200, tallest initial element)` px), where the walls sit; Rust reads it from the grid, so it stays DOM-blind and no FFI slot is added. An element whose home rect lies entirely outside the bound is parked: its particles carry `FLAG_PARKED` (bit 2 of the dynamic view's `flags`), skip P2G, the grid update, G2P and the particle AABB (the dirty region shrinks), `scroll_shift`, splash, shake and the merge damage; the element is held at rest (s 1, restAlpha 1). It is unparked once its home rect lies 64 px inside the bound on every side, or as soon as it overlaps the world (the viewport in body mode, the container's visible window in container mode), whichever comes first; in that tick (also a 0-step tick) each of its particles is placed at rest (`home + rest_uv`, v = 0, C = 0, J = 1, F = I, torn cleared) and the element is at rest with no previous rect sample, so its next home velocity is 0. A dragged or an inactive (w == 0) element is never parked. A parked element keeps its particle share (the budget and the state stride are unchanged; re-entry needs no redistribute); its particles count as unplaced, so a redistribute that gives one a new home places it on its new target instead of letting it crawl in from the wall. Canvas2D skips a particle with `FLAG_PARKED` and every particle of an inactive slot (w == 0: hidden, or unobserved until the redistribute; WebGPU's element record already hides it), which closes W76's w == 0 item; WebGPU packs a parked particle off-screen. Chosen in the brainstorm (Dennis 2026-10-13, saga dec_645b54e4); the bound, the "or overlaps the world" unpark, the unplaced rule and the inactive rule are the plan's resolutions.
Consequence: invisible: a parked element is always off-screen (it unparks the frame it overlaps the world), and at rest both renderers draw the exact rest shape from the rects anyway. Liquid that was in flight when its element left comes back at rest (plan validation: worst |x − target| 0.00015 px and restAlpha 1 in the re-entry frame). The on-screen simulation is bit-identical with parking on or off (19 160 of 19 160 words after a splash, a shake and a scroll), and the dirty region holds 0.385 × the cells with a far card parked (native frame 2.40 against 3.87 ms with 40 % of the particles parked). The spec's "re-entry needs the rect ≥ 64 px inside the bound" gains "or overlapping the world" (a rect taller than the margin − 64 px would otherwise be on screen while parked). A splash on a parked element (API only; it is off-screen) is ignored. An element that leaves the bound only partly keeps its wall-clamped liquid until it parks or re-forms (W80's parked minor, narrowed). The approved W67 lock-probe test changes for its −1000 px leg (the element now parks instead of clamping to the wall).
Decision: PENDING

### D81-2: Resize — one logged resize_world per growth step, never shrinking
Proposal: a new scalar call `FluidCore::resize_world(w, h) -> bool`; the 7-arg constructor stays frozen. It grows the grid to cover a world of at least w × h px (each axis clamped to [64, 8192] px like the constructor, a non-finite or non-positive extent keeps its axis; never shrinks): the cell, the margin and the lattice origin stay, so every particle keeps its grid position and W80's lattice phase; only the right and bottom walls move out; only the three grid arrays are reallocated, so every view pointer stays valid. TS keeps a copy of the world (`world.ts`, Rust's clamp mirrored). `resizeCanvas()` (the window's `resize` in body mode, the container's ResizeObserver in container mode) measures the world again and, when an axis outgrew the copy, grows that axis to max(need, ⌈1.25 × current⌉) capped at 8192 px and calls `resize_world` once from the handler, never inside a frame, with one `console.info`: `[liquiddom] the viewport outgrew the liquid's world; the grid grew to W×H px.` After a failed frame the core is not called (it may be poisoned). The parking bound grows with the world, so elements that are now inside unpark at rest.
Consequence: one reallocation per growth step, outside `tick` (spec §2: "one explicit, logged reallocation"); the 1.25 headroom bounds a window dragged from 1280 to 2560 px wide to at most four reallocations and four lines. Body mode rarely grows (the world starts at the screen size; zooming out and a move to a larger screen are the triggers); a container that grows is the common case. Memory follows the largest world and is never given back. A world beyond 8192 px stays clamped as before.
Decision: PENDING

### D81-3: Container world — the container's client box, not its scroll range
Proposal: in container mode the world is the container's client box (`clientWidth × clientHeight`) instead of W64's `max(client, scroll)`. Since W80 buffer space in container mode is the container's visible window (the canvas is translated onto it), so the world, and with it the parking bound (world + margin), is that window: content scrolled far away parks as in body mode. The ResizeObserver that already resizes the canvas drives D81-2's growth. Spec §2 "(or the container's maximum in container mode)" is amended.
Consequence: a long container's grid shrinks to its window plus the margin (less memory); content beyond the margin parks instead of being simulated against the walls. A content change that only grows the scroll range reallocates nothing. The W80 container scene and the D72-6 container tests are unaffected (their elements stay inside the window plus the margin; plan validation: the canvas2d suite and the Metal container tests pass).
Decision: PENDING

The solver skips a parked particle in `particle_bounds`, P2G, G2P (and the fused AABB), `compute_targets` (no target: the pin and maxDev skip it) and `measure_max_f_dev`; `update_rest_state_with_f` writes rest for a parked element; `scroll::apply` skips parked particles and `shifts_with_scroll` is `!dragged && !parked`; `splash` on a parked id returns false; `shake` and `hold_dragged` skip parked elements. `resize_world` → `Grid::resize_world` (+ `invalidate_bounds`).

**Runtime (TS).** `createFluidRuntime` measures the world (`world.ts` `measureWorld`: body `max(screen, inner)`, container the client box), passes it to the frozen constructor and to `buildRuntime`, which keeps `clampWorld(world)`. `resizeCanvas()` ends with `growWorld()`: `grownWorld(world, measureWorld(container))`; null → nothing; else `world = next`, `core.resize_world(next.w, next.h)` and, when it grew, one `console.info`. //! W81: parking and resize (slice-6 design §4; spec §2 grid and "Walls and off-screen elements";
//! D81-1, D81-2).
//!
//! Scenario tests drive the real `FluidCore` over the acceptance layout (`scenario_tests`) plus a
//! far card (`FAR_ID`, 320×160 r16, 2400 px down: entirely below the world 1280×800 plus the
//! 200 px margin, so it parks). A page scrolled by `S` px is driven the way TS drives it (W80):
//! every rect is written `S` px higher, then `scroll_shift(0, Δ, 0, 0)` runs before the tick.
//! `set_parking_off(true)` is the test-only switch that runs the W80 engine for comparison.
#![allow(clippy::needless_range_loop)]

use super::api::FluidCore;
use super::elements::Rect;
use super::grid::{Grid, WORLD_MAX_PX};
use super::layout::{FLAG_PARKED, INTERACTION_DRAGGED, ST_MAX_DEV, ST_REST_ALPHA, ST_S};
use super::parking::{Bounds, UNPARK_INSET_PX, bound, inside_by, outside, overlaps, world};
use super::scenario_tests::{AREA_HINT_PX2, CARD, LAYOUT, SEED, acceptance_core, frames, slot};

const DT: f32 = 1.0 / 60.0;
const FAR_ID: usize = 4;
/// Entirely below the bound (800 + 200 px) at scroll 0.
const FAR_RECT: [f32; 5] = [480.0, 2400.0, 320.0, 160.0, 16.0];
/// f32 rounding of a placed position (px).
const PLACE_EPS_PX: f32 = 1e-3;
/// W80's bound for "equal to the unscrolled core up to f32 rounding".
const ROUNDING_PX: f32 = 0.01;

fn frame(core: &mut FluidCore) -> u32 {
    core.tick(DT, 0.0, 0.0, 0.0, 0.0, false, 0.0, 0.0)
}

/// The acceptance layout plus the far card, scrolled `scroll_y` px down.
fn write_all(core: &mut FluidCore, scroll_y: f32) {
    for (id, e) in LAYOUT.iter().enumerate() {
        let mut r = *e;
        r[1] -= scroll_y;
        core.write_element(id, slot(r));
    }
    let mut far = FAR_RECT;
    far[1] -= scroll_y;
    core.write_element(FAR_ID, slot(far));
}

fn far_core(parking: bool) -> FluidCore {
    let mut c = FluidCore::new(8000, 32, 1280.0, 800.0, AREA_HINT_PX2, 180.0, SEED);
    c.set_parking_off(!parking);
    write_all(&mut c, 0.0);
    c.redistribute();
    c
}

/// One frame of the page scrolled from `from` to `to` px (no inertia): rects, shift, tick.
fn scroll_frame(core: &mut FluidCore, from: f32, to: f32) {
    write_all(core, to);
    core.scroll_shift(0.0, to - from, 0.0, 0.0);
    frame(core);
}

/// Grid-unit positions and velocities (bits) of the elements' particles, in index order.
fn bits_of(core: &FluidCore, ids: &[usize]) -> Vec<u32> {
    let (pos, vel) = (core.position_bits(), core.velocity_bits());
    let n = core.particle_capacity() as usize;
    let mut out = Vec::new();
    for &id in ids {
        for i in core.particle_indices_of(id as u32) {
            out.extend([pos[i], pos[n + i], vel[i], vel[n + i]]);
        }
    }
    out
}

fn worst_target_dev(core: &FluidCore, id: usize) -> f32 {
    core.particle_indices_of(id as u32)
        .into_iter()
        .map(|i| {
            let (x, y) = core.particle_px(i);
            let (tx, ty) = core.target_px(i).unwrap();
            (x - tx).hypot(y - ty)
        })
        .fold(0.0, f32::max)
}

fn rect(x: f32, y: f32, w: f32, h: f32) -> Rect {
    Rect { x, y, w, h, r: 0.0 }
}

import { createManualClock, rafClock, type FrameClock } from "../../packages/core/ts/src/clock";

  throw new TypeError(`[long-page] ?renderer must be canvas2d, webgpu or auto, got "${rendererRaw}"`);
}

const clockRaw = query.get("clock") ?? "raf";

  throw new TypeError(`[long-page] ?clock must be "raf" or "manual", got "${clockRaw}"`);

let snapshot: { canvas: HTMLCanvasElement; ctx: CanvasRenderingContext2D } | null = null;

function byId(id: string): HTMLElement {
  const el = document.getElementById(id);
  if (!el) throw new Error(`[long-page] #${id} not found`);
  return el;
}

function runtime(): FluidRuntime {
  const rt = instance ? runtimeOf(instance) : undefined;
  if (!rt) throw new Error("[long-page] no instance yet");
  return rt;
}

function capture(): void {
  const src = runtime().canvas;
  if (!snapshot) {
    const canvas = document.createElement("canvas"); // detached: never in the DOM
    const ctx = canvas.getContext("2d", { willReadFrequently: true });
    if (!ctx) throw new Error("[long-page] no 2d context for the pixel snapshot");
    snapshot = { canvas, ctx };
  }
  if (snapshot.canvas.width !== src.width) snapshot.canvas.width = src.width;
  if (snapshot.canvas.height !== src.height) snapshot.canvas.height = src.height;
  snapshot.ctx.clearRect(0, 0, snapshot.canvas.width, snapshot.canvas.height);
  snapshot.ctx.drawImage(src, 0, 0);
}

async function start(): Promise<void> {
  instance = await LiquidDOM.create({ seed: 1, particles: 8000, maxElements: 8, clock, renderer, autoObserve: false });
  for (const id of IDS) slots.set(id, instance.observe(byId(id)));
  await new Promise<void>((resolve) => queueMicrotask(resolve)); // the batched redistribute
}

const ready = start();
ready.catch((err: unknown) => {
  console.error("[long-page] start failed", err);
});

const hook: LongPageHook = {
  ready,
  advance(frames) {
    if (!manual) throw new Error("[long-page] advance() needs ?clock=manual");
    // No frame rendered in this task: keep the previous snapshot (W71 ward-review M3).
    if (manual.advance(frames) === 0) return;
    capture();
  },
  pixels() {
    if (!snapshot) throw new Error("[long-page] pixels() needs a prior advance()");
    return snapshot.ctx.getImageData(0, 0, snapshot.canvas.width, snapshot.canvas.height);
  },
  restAlpha: () => IDS.map((id) => runtime().elementState(byId(id))?.restAlpha ?? Number.NaN),
  parked() {
    const bridge = runtime().bridge;
    const cap = bridge.particleCapacity;
    const st = bridge.staticView();
    const dyn = bridge.dynamicView();
    return IDS.map((id) => {
      const slot = slots.get(id);
      let mine = 0;
      let flagged = 0;
      for (let i = 0; i < cap; i++) {
        if (st[Stat.HOME * cap + i] !== slot) continue;
        mine += 1;
        if (((dyn[Dyn.FLAGS * cap + i] as number) & FLAG_PARKED) !== 0) flagged += 1;
      }
      return mine > 0 && flagged === mine;
    });
  },
  world: () => ({ ...runtime().world }),
  shake() {
    if (!instance) throw new Error("[long-page] no instance yet");
    instance.shake();
  },
};
(window as Window & { __longPage?: LongPageHook }).__longPage = hook;

/** Canvas pixels of the last snapshot with alpha > 128 and |rgb − colour|₁ < 60. */
async function colourPixels(page: Page, sel: string): Promise<number> {
  return page.evaluate((rgb) => {
    const d = window.__longPage!.pixels().data;
    let n = 0;
    for (let o = 0; o < d.length; o += 4) {
      if (d[o + 3] > 128 && Math.abs(d[o] - rgb[0]) + Math.abs(d[o + 1] - rgb[1]) + Math.abs(d[o + 2] - rgb[2]) < 60) n++;
    }
    return n;
  }, COLOURS[sel]!);
}

async function framesUntilRest(page: Page, max: number): Promise<number> {
  return page.evaluate((n) => {
    const h = window.__longPage!;
    for (let f = 1; f <= n; f++) {
      h.advance(1);
      if (h.restAlpha().every((a) => a === 1)) return f;
    }
    return -1;
  }, max);

// W81 (slice design §11): parking lowers the frame time on a long page. The long page at the top
// (#far1 and #far2 parked: about 88 % of the particles, by area) against the same page with
// ?compact=1 (all four elements on the first screen, nothing parked); both at rest on the manual
// clock, so the ratio isolates the simulated particles (the Rust plan validation: 2.40 vs
// 3.87 ms per frame with 40 % of the particles parked, native release build).
const W81_PARKED_OVER_COMPACT_MAX = 0.6;
const W81_COST_FRAMES = 60;
const W81_COST_RUNS = 3;

/** Median wall ms of `advance(1)` over W81_COST_FRAMES frames of the long page at rest. */
async function w81FrameMedianMs(page: Page, compact: boolean): Promise<number> {
  await page.goto(`/scenes/long-page.html?renderer=canvas2d&clock=manual${compact ? "&compact=1" : ""}`);
  await page.waitForFunction(() => window.__longPage !== undefined, undefined, { timeout: 15_000 });
  await page.evaluate(() => window.__longPage!.ready);
  await page.evaluate(() => window.__longPage!.advance(120));
  await page.mouse.move(1279, 799);
  const parked = await page.evaluate(() => window.__longPage!.parked());
  expect(parked, compact ? "compact: nothing parked" : "long page: the far cards parked").toEqual(compact ? [false, false, false, false] : [false, false, true, true]);
  return page.evaluate((n) => {
    const out: number[] = [];
    for (let f = 0; f < n; f++) {
      const t = performance.now();
      window.__longPage!.advance(1);
      out.push(performance.now() - t);
    }
    out.sort((a, b) => a - b);
    return out[Math.floor(out.length / 2)];
  }, W81_COST_FRAMES);
}

//! W81 (D81-1, slice-6 design §4; spec §2 "Walls and off-screen elements"): parking. An element
//! whose home rect lies entirely outside the world plus the grid margin (the walls) is parked:
//! its particles carry `FLAG_PARKED`, skip the transfers (P2G, grid, G2P), the particle AABB, the
//! scroll shift, splash and shake, and both renderers skip them; the element is held at rest. It is
//! unparked once its home rect lies `UNPARK_INSET_PX` inside the bound on every side, or as soon as
//! it overlaps the world (the viewport in body mode, the container's visible window in container
//! mode), whichever comes first: its particles are then placed at rest at once (`home + rest_uv`,
//! v = 0, C = 0, J = 1, F = I) and the element is at rest (s = 1, restAlpha 1) with no previous rect
//! sample, so the frame it re-enters shows it at rest and its next home velocity is 0. A dragged
//! or inactive element is never parked. The particle budget is unchanged: a parked element keeps
//! its particles, so re-entry needs no redistribute.
//!
//! Rust stays DOM-blind: the bound is the world `create()` (or `resize_world`) gave the grid plus
//! its margin, in buffer px. No FFI change besides the particle flag bit.

use super::access::{rd, wr};
use super::elements::{Elements, Rect};
use super::grid::Grid;
use super::layout::FLAG_PARKED;
use super::particles::Particles;

/// D81-1: a parked element comes back once its home rect is this many px inside the bound on
/// every side (or once it overlaps the world).
pub const UNPARK_INSET_PX: f32 = 64.0;

/// A box in buffer px, `[x0, x1] × [y0, y1]`.
#[derive(Clone, Copy, Debug, PartialEq)]
pub struct Bounds {
    pub x0: f32,
    pub y0: f32,
    pub x1: f32,
    pub y1: f32,
}

/// The parking bound: the world plus the grid margin on every side (where the walls sit, up to
/// W80's half-cell lattice drift).
pub fn bound(g: &Grid) -> Bounds {
    Bounds {
        x0: -g.margin_px,
        y0: -g.margin_px,
        x1: g.world_w_px + g.margin_px,
        y1: g.world_h_px + g.margin_px,
    }
}

/// The world itself, `[0, w] × [0, h]` (the viewport, or the container's visible window).
pub fn world(g: &Grid) -> Bounds {
    Bounds {
        x0: 0.0,
        y0: 0.0,
        x1: g.world_w_px,
        y1: g.world_h_px,
    }
}

/// `r` lies entirely outside `b` (touching counts as outside). NaN gives false.
pub fn outside(r: &Rect, b: &Bounds) -> bool {
    r.x + r.w <= b.x0 || r.x >= b.x1 || r.y + r.h <= b.y0 || r.y >= b.y1
}

/// `r` lies inside `b` with at least `inset` px to spare on every side. NaN gives false.
pub fn inside_by(r: &Rect, b: &Bounds, inset: f32) -> bool {
    r.x >= b.x0 + inset
        && r.x + r.w <= b.x1 - inset
        && r.y >= b.y0 + inset
        && r.y + r.h <= b.y1 - inset
}

/// `r` overlaps `b` with a positive area. NaN gives false.
pub fn overlaps(r: &Rect, b: &Bounds) -> bool {
    r.x < b.x1 && r.x + r.w > b.x0 && r.y < b.y1 && r.y + r.h > b.y0
}

/// Element `id`'s parked state for the rects TS wrote this frame (D81-1).
fn wants_parked(e: &Elements, id: usize, b: &Bounds, w: &Bounds) -> bool {
    if e.is_dragged(id) {
        return false;
    }
    let Some(r) = e.home_rect(id, false) else {
        return false;
    };
    if e.is_parked(id) {
        !(inside_by(&r, b, UNPARK_INSET_PX) || overlaps(&r, w))
    } else {
        outside(&r, b)
    }
}

/// Parks and unparks every element for this frame's rects; returns true when any element changed.
/// A changed element is put at rest at once (`Elements::rest_now`); then one particle pass
/// (`sync_particles`) flags the newly parked particles and places the newly unparked ones at
/// rest. O(elements) on a frame without a change. No allocation, no panic.
pub fn update(p: &mut Particles, g: &Grid, e: &mut Elements, reduced_motion: bool) -> bool {
    let (b, w) = (bound(g), world(g));
    let mut changed = false;
    for id in 0..e.cap {
        let now = wants_parked(e, id, &b, &w);
        if now != e.is_parked(id) {
            e.set_parked(id, now);
            e.rest_now(id);
            changed = true;
        }
    }
    if changed {
        sync_particles(p, g, e, reduced_motion);
    }
    changed
}

/// Brings every particle's `FLAG_PARKED` in line with its home's parked state. A parked particle
/// keeps its position and has `placed = false` (a redistribute that gives it a new home places it
/// at its new target, `pool::redistribute`, instead of letting it crawl in from where it was). A particle that stops being parked is
/// placed at rest at its target with its kinematics reset (`reset_kinematics`: v, C, J, F, torn);
/// without a target (its slot went inactive) it only loses the flag and stays unplaced. A homeless
/// particle never carries the flag.
pub fn sync_particles(p: &mut Particles, g: &Grid, e: &Elements, reduced_motion: bool) {
    for i in 0..p.cap {
        let home = p.home_of(i);
        if home.is_some_and(|h| e.is_parked(h)) {
            if let Some(f) = p.flags.get_mut(i) {
                *f |= FLAG_PARKED;
            }
            if let Some(placed) = p.placed.get_mut(i) {
                *placed = false;
            }
            continue;
        }
        if !p.is_parked(i) {
            continue;
        }
        if let Some(f) = p.flags.get_mut(i) {
            *f &= !FLAG_PARKED;
        }
        let target =
            home.and_then(|h| e.target_px(h, rd(&p.rest_u, i), rd(&p.rest_v, i), reduced_motion));
        if let Some((tx, ty)) = target {
            let (gx, gy) = g.to_grid(tx, ty);
            let (gx, gy) = g.clamp_pos(gx, gy);
            wr(&mut p.x, i, gx);
            wr(&mut p.y, i, gy);
            p.reset_kinematics(i);
            if let Some(placed) = p.placed.get_mut(i) {
                *placed = true;
            }
        }
    }
}

    /// `[WORLD_MIN_PX, WORLD_MAX_PX]`; a non-finite or non-positive extent keeps that axis) and
    /// reallocates the grid arrays for it. Never shrinks. The cell, the margin and the origin stay,
    /// so every particle keeps its grid position and W80's lattice phase (`origin − base_origin_px`);
    /// only the right and bottom walls move out. The region is reset (the caller invalidates the
    /// fused AABB). Allocates: called outside `tick` only. Returns true when the world grew.
    pub fn resize_world(&mut self, world_w_px: f32, world_h_px: f32) -> bool {
        let grow = |v: f32, now: f32| {
            if positive(v) {
                v.clamp(WORLD_MIN_PX, WORLD_MAX_PX).max(now)
            } else {
                now
            }
        };
        let ww = grow(world_w_px, self.world_w_px);
        let wh = grow(world_h_px, self.world_h_px);
        if ww <= self.world_w_px && wh <= self.world_h_px {
            return false;
        }
        let cells = |extent: f32| {
            ((extent + 2.0 * self.margin_px) * self.inv_cell).ceil() as usize + STENCIL_GUARD_CELLS
        };

        let h = cells(wh).max(self.h);
        let n = w * h;
        self.world_w_px = ww;
        self.world_h_px = wh;
        self.w = w;
        self.h = h;
        self.mass = vec![0.0; n];
        self.mvx = vec![0.0; n];
        self.mvy = vec![0.0; n];

    }

 * W81 (D81-2, D81-3): the world the fluid grid covers, in CSS px of buffer space. The core gets
 * it once in its constructor (frozen 7 args, D64-4) and grows it with `resize_world` (D81-2). Rust
 * clamps every extent to [WORLD_MIN_PX, WORLD_MAX_PX] (`src/fluid/grid.rs`); `clampWorld` mirrors
 * that, so the runtime's copy equals the core's world.
 * - Body mode (B2): `max(screen, inner)` per axis.
 * - Container mode (D81-3): the container's client box, its visible window, which is buffer space
 *   since W80 (the canvas is translated onto it). The scroll range is no longer part of the world,
 *   so content scrolled far away parks (D81-1) instead of being simulated.
 */
export const WORLD_MIN_PX = 64;
export const WORLD_MAX_PX = 8192;
/** Rust's fallback for a non-finite or non-positive extent (`DEFAULT_WORLD_W_PX`, `DEFAULT_WORLD_H_PX`). */
const DEFAULT_WORLD: WorldSize = { w: 1280, h: 800 };
/**
 * D81-2: an axis that outgrew the world grows to at least this many times its current extent, so a
 * window dragged wider reallocates a few times, not on every resize event.
 */
export const WORLD_GROWTH = 1.25;
/** D81-2: the one console.info per reallocation; the new world follows as "W×H px.". */
export const WORLD_RESIZE_INFO = "[liquiddom] the viewport outgrew the liquid's world; the grid grew to";

export interface WorldSize {
  readonly w: number;
  readonly h: number;
}

/** B2 / D81-3: body mode `max(screen, inner)` per axis; container mode the container's client box. At least 1 px. */
export function measureWorld(container?: HTMLElement): WorldSize {
  if (container) {
    return { w: Math.max(container.clientWidth, 1), h: Math.max(container.clientHeight, 1) };
  }
  const sw = typeof screen !== "undefined" ? screen.width || 0 : 0;
  const sh = typeof screen !== "undefined" ? screen.height || 0 : 0;
  return { w: Math.max(sw, window.innerWidth || 0, 1), h: Math.max(sh, window.innerHeight || 0, 1) };
}

/** Rust's `world_extent` per axis: a positive finite extent clamped to [64, 8192], else 1280 × 800. */
export function clampWorld(s: WorldSize): WorldSize {
  const c = (v: number, fallback: number): number =>
    Number.isFinite(v) && v > 0 ? Math.min(WORLD_MAX_PX, Math.max(WORLD_MIN_PX, v)) : fallback;
  return { w: c(s.w, DEFAULT_WORLD.w), h: c(s.h, DEFAULT_WORLD.h) };
}

/**
 * D81-2: the world to grow to when `need` (clamped like Rust) outgrows `current` on an axis, else
 * null. Each outgrown axis grows to max(need, ⌈current × WORLD_GROWTH⌉), capped at WORLD_MAX_PX;
 * the other axis stays. Never shrinks.
 */
export function grownWorld(current: WorldSize, need: WorldSize): WorldSize | null {
  const n = clampWorld(need);
  const grow = (now: number, want: number): number =>
    want > now ? Math.min(WORLD_MAX_PX, Math.max(want, Math.ceil(now * WORLD_GROWTH))) : now;
  const next = { w: grow(current.w, n.w), h: grow(current.h, n.h) };
  return next.w === current.w && next.h === current.h ? null : next;
}
