## Part 2

Written after the W83.0 gate (Step 7), against `89973ee` (every `Decision:` line approved 2026-10-14). Steps 1–6 of W83.0 are done (`7a67ce7`, `6324f09`, `89973ee`).

**Architecture:** gravity reaches the engine as a high-pass. Rust's new `gravity.rs` keeps a per-core low-pass `g_lp` (f64, τ 0.5 s, advanced once per fixed step) and turns each fixed step's `g` (from `tick`'s existing `gx, gy`) into a body acceleration `1.5 · (g − g_lp)`, clamped to 2000 px/s²; below 0.5 px/s² it snaps to exactly 0 (`g_lp = g`). `tick` hands it to the grid in cells/s² (`Grid::set_body_accel`), and `update_velocities` adds it to the cells with mass after momentum → velocity, before the walls and the CFL cap; a zero body acceleration is skipped, so a core without a gravity change is bit-identical to W82. One new scalar call, `seed_gravity(gx, gy)`, sets `g_lp = g`. TypeScript's new `gravity.ts` (`GravityInput`, one per instance) gives every frame's `tick` the source's gravity (`none` 0; `fixed` `normalize(vector) · strength`; `orientation` the projected `deviceorientation` direction, rotated by `screen.orientation.angle`, with a 2° dead band; 0 under reduced motion) and asks for `seed_gravity` before the tick when a gravity starts fresh. The facade gains `setGravity(partial)` (`mergeGravity`, atomic like `setMaterial`). A new live scene `demo/scenes/tilt.html` shows it.

**Tech stack:** Rust (edition 2024, wasm-bindgen), TypeScript (strict), Vitest 4 (jsdom, fake canvas, test backend; real WASM in `fluid-ffi.test.ts`), Playwright 1.63.0 (canvas2d blocking; WebGPU local on Metal, W71.0 fallback B).

**Design resolutions this plan makes (within the approved decisions; presented with the plan):**
1. **Seeding is one new scalar call, `seed_gravity(gx, gy)`.** D83-4 seeds "at create() and on a source switch", and the core cannot tell a switch from a change by g alone (a flat phone at (0, 0) that tilts must act; `fixed` → `none` must not). It changes no layout, slot or constructor argument; the gravity itself still travels through `tick`'s `gx, gy` (the README's "slice 6 adds scalar calls only"). TS calls it inside the frame, right before `tick`, so the create-time call order (ending with `set_reduced_motion`, pinned by `runtime.test.ts`) is unchanged.
2. **"Starts fresh" also covers the first orientation reading and the end of reduced motion.** An `orientation` source has no gravity until its first `deviceorientation` event; without a seed that reading would be a step from 0 and slosh at load, which D83-4 rejected. Reduced motion hands the core 0 (the W46 test stays as written), so the first frame with motion seeds as well; Rust also seeds on every reduced-motion tick, so a core driven without TS never stores up a slosh either.
3. **The body acceleration lives on the grid** (`Grid::body_accel`, set per fixed step by `tick`), not in `StepInput`: no solver signature and none of the eight `StepInput` test literals change; `(0, 0)` is skipped bit for bit.
4. **The low-pass advances once per fixed step** (W83.0), so a 0-step tick changes nothing and the manual clock stays deterministic; the snap step for a 90° change at full strength is 239 (≈ 8τ).
5. **θ is read every frame**, so an OS rotation flip acts at once (one small slosh, W83.0 Q3); the dead band is on the 3D device direction, so a flat phone is bit-quiet.
6. **The tilt scene reuses the acceptance layout** (three 140×48 r24 pills and a 320×180 r16 card, 8000 particles), so its kernel radius is W83.0's 7.09 px and W67's 8 px `outside` margin bounds "rect + kernel" in the browser.
7. **No baseline moves, none is added.** Every existing scene runs `none`: it seeds (0, 0) once and ticks with (0, 0), which Rust skips bit for bit (Rust 6, 11). W83.4 runs the Docker Canvas2D suite without `--update-snapshots`.

//! W83 (D83-1, D83-2, D83-4): gravity as a high-pass, so only changes in gravity act.
//!
//! TS hands the page's gravity to every `tick(…, gx, gy)` in px/s² (CSS axes: x right, y down;
//! `strength · normalize(vector)` for `fixed`, the projected device tilt for `orientation`, 0 for
//! `none` and under reduced motion). Rust keeps a low-pass `g_lp` per core (f64, advanced once per
//! fixed step with `a = 1 − exp(−FIXED_DT/τ)`, so a 0-step tick changes nothing and the result does
//! not depend on the frame rate) and hands the grid `GRAVITY_SCALE · (g − g_lp)`, clamped to
//! `GRAVITY_CLAMP_PX_S2`, for the cells with mass (`Grid::update_velocities`, after momentum →
//! velocity, before the walls and the CFL cap). A constant gravity therefore moves nothing: a
//! change sloshes the liquid and the unchanged home spring brings it home (D83-1, a subtle lean).
//! Below `GRAVITY_SNAP_PX_S2` the high-pass snaps to exactly 0 (`g_lp = g`), so ≈ 8τ after a change
//! the engine runs bit-identical to a core without gravity (W83.0 Q4: a low-pass alone never
//! reaches g). `seed` (`FluidCore::seed_gravity`) sets `g_lp = g`: TS seeds at `create()`, on a
//! source switch, on the first orientation reading and when reduced motion ends (D83-4), so none
//! of them sloshes. Under reduced motion `tick` seeds on every call (no gravity acts).

use super::clock::FIXED_DT_S;

/// D83-2: the high-passed gravity is scaled by this before it reaches the grid.
pub const GRAVITY_SCALE: f32 = 1.5;
/// D83-2: the low-pass time constant (s).
pub const GRAVITY_TAU_S: f32 = 0.5;
/// D83-1: `|GRAVITY_SCALE · g_hp|` is clamped to this (px/s²), below the home spring's saturation
/// (`a_max` 3200 px/s² at full stiffness), so the liquid never leaves its element (W83.0 Q1).
pub const GRAVITY_CLAMP_PX_S2: f32 = 2000.0;
/// D83-1: `|g_hp|` below this (px/s²) snaps to exactly 0 (a lean ≤ 0.003 px at scale 1.5).
pub const GRAVITY_SNAP_PX_S2: f32 = 0.5;
/// Input sanitising: each axis of g is clamped to ± this (px/s²); NaN and ±Inf give 0.
pub const GRAVITY_INPUT_MAX_PX_S2: f32 = 1.0e5;

/// Per axis: a finite value is clamped to ±`GRAVITY_INPUT_MAX_PX_S2`; NaN and ±Inf give 0.
pub fn sanitized(gx: f32, gy: f32) -> (f32, f32) {
    let _ = (gx, gy, GRAVITY_INPUT_MAX_PX_S2); // W83.1 red stub: W83.2 keeps finite input
    (0.0, 0.0)
}

/// The per-core gravity low-pass of D83-1 (px/s², f64).
#[derive(Clone, Copy, Debug, PartialEq)]
pub struct HighPass {
    lp_x: f64,
    lp_y: f64,
}

impl Default for HighPass {
    /// `g_lp = 0`: a core nobody seeds treats its first gravity as a change.
    fn default() -> HighPass {
        HighPass {
            lp_x: 0.0,
            lp_y: 0.0,
        }
    }
}

impl HighPass {
    /// D83-4: `g_lp = g` (sanitised), so the next step with the same g returns exactly 0.
    pub fn seed(&mut self, gx: f32, gy: f32) {
        let (x, y) = sanitized(gx, gy);
        self.lp_x = f64::from(x);
        self.lp_y = f64::from(y);
    }

    /// The low-pass `g_lp` (px/s²).
    pub fn low_pass(&self) -> (f64, f64) {
        (self.lp_x, self.lp_y)
    }

    /// One fixed step with gravity `g` (px/s², sanitised): returns the body acceleration for the
    /// grid, `GRAVITY_SCALE · (g − g_lp)` clamped to `GRAVITY_CLAMP_PX_S2` along its direction
    /// (px/s²), then advances the low-pass by `a · (g − g_lp)`. Below `GRAVITY_SNAP_PX_S2` it sets
    /// `g_lp = g` and returns exactly `(0, 0)`.
    pub fn step(&mut self, gx: f32, gy: f32) -> (f32, f32) {
        let _ = (gx, gy, FIXED_DT_S, GRAVITY_TAU_S, GRAVITY_SCALE); // W83.1 red stub: W83.2 high-passes
        let _ = (GRAVITY_CLAMP_PX_S2, GRAVITY_SNAP_PX_S2);
        (0.0, 0.0)
    }
}

function capture(): void {
  const src = liquidCanvas();
  if (!snapshot) {
    const canvas = document.createElement("canvas"); // detached: never in the DOM
    const ctx = canvas.getContext("2d", { willReadFrequently: true });
    if (!ctx) throw new Error("[tilt] no 2d context for the pixel snapshot");
    snapshot = { canvas, ctx };
  }
  const { canvas, ctx } = snapshot;
  if (canvas.width !== src.width) canvas.width = src.width;
  if (canvas.height !== src.height) canvas.height = src.height;
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.drawImage(src, 0, 0);
}

  restAlpha: () => elements.map((el) => (instance ? runtimeOf(instance)?.elementState(el)?.restAlpha : undefined) ?? Number.NaN),
  setAngle,

    const data = pixels().data;

    for (let i = 0; i < data.length; i++) {

    const sx = img.width / cr.width;
    const sy = img.height / cr.height;
    const rects = elements.map((e) => e.getBoundingClientRect());

    for (let py = 0; py < img.height; py++) {
      const y = (py + 0.5) / sy + cr.top;

        if (!rects.some((r) => x >= r.left - marginPx && x <= r.right + marginPx && y >= r.top - marginPx && y <= r.bottom + marginPx)) out++;

 * W83 (D83-1, D83-4, D83-5): helpers for the tilt scene (demo/scenes/tilt.html, `window.__tilt`),
 * shared by e2e/tilt.spec.ts (canvas2d) and the W83 block of e2e/webgpu-robust.spec.ts (webgpu-hw).

 */

import { VIEWPORT } from "./projects";

/** 2 s idle before a tilt (scene step 1). */
export const TILT_IDLE_FRAMES = 120;
/** NORTH-STAR's re-form budget: every restAlpha back to 1 within 3 s. */
export const TILT_BUDGET_FRAMES = 180;
/** W67's outside metric grows each rect by 8 px, above the acceptance layout's 7.09 px kernel (W83.0 Q1). */
export const TILT_MARGIN_PX = 8;
/** The snap engages ≈ 8τ after a 90° step (W83.0 Q4: step 239); the settled frame is read after it. */
export const TILT_SETTLE_FRAMES = 300;

export async function gotoTilt(page: Page, renderer: "canvas2d" | "webgpu", query = ""): Promise<void> {
  await page.goto(`/scenes/tilt.html?renderer=${renderer}&clock=manual${query}`);
  await page.waitForFunction(() => window.__tilt !== undefined, undefined, { timeout: 15_000 });
  await page.evaluate(() => window.__tilt!.ready);
  await page.evaluate(async () => {
    await document.fonts.ready;
  });
  await page.mouse.move(VIEWPORT.width - 1, VIEWPORT.height - 1);
}

export interface TiltRun {
  /** The smallest restAlpha seen after the tilt (< 1: the liquid leaned). */
  minAlpha: number;
  /** Opaque pixels outside the rects + TILT_MARGIN_PX in the frame before the tilt, and the most during it. */
  outsideBefore: number;
  outsidePeak: number;
  /** Frames from the tilt until every restAlpha is 1 again (-1: never within TILT_SETTLE_FRAMES). */
  restFrame: number;
  /** The frame before the tilt and the frame TILT_SETTLE_FRAMES after it. */
  hashBefore: string;
  hashAfter: string;
}

/** Idles, turns gravity to `deg` (from straight down) and runs TILT_SETTLE_FRAMES frames, one at a time. */
export async function tiltAndSettle(page: Page, deg: number): Promise<TiltRun> {
  await page.evaluate((n) => window.__tilt!.advance(n), TILT_IDLE_FRAMES);
  return page.evaluate(
    ([angle, margin, budget, settle]) => {
      const h = window.__tilt!;
      const hashBefore = h.hash();
      const outsideBefore = h.outside(margin);
      h.setAngle(angle);
      let minAlpha = 1;
      let outsidePeak = outsideBefore;
      let restFrame = -1;
      for (let f = 1; f <= settle; f++) {
        h.advance(1);
        const a = h.restAlpha();
        minAlpha = Math.min(minAlpha, ...a);
        if (f <= budget) outsidePeak = Math.max(outsidePeak, h.outside(margin));
        if (restFrame < 0 && minAlpha < 1 && a.every((x) => x === 1)) restFrame = f;
      }
      return { minAlpha, outsideBefore, outsidePeak, restFrame, hashBefore, hashAfter: h.hash() };
    },
    [deg, TILT_MARGIN_PX, TILT_BUDGET_FRAMES, TILT_SETTLE_FRAMES] as const,
  );
}

        let (x, y) = sanitized(gx, gy);
        let (gx, gy) = (f64::from(x), f64::from(y));
        let (hx, hy) = (gx - self.lp_x, gy - self.lp_y);

            self.lp_x = gx;
            self.lp_y = gy;
            return (0.0, 0.0);

export function fixedGravity(vector: readonly [number, number], strength: number): [number, number] {
  const len = Math.hypot(vector[0], vector[1]);
  if (!(len > 0) || !Number.isFinite(len) || !(strength > 0)) return [0, 0];
  // `+ 0` turns a -0 into 0, so a sign never leaks into the FFI or the tests.
  return [(vector[0] / len) * strength + 0, (vector[1] / len) * strength + 0];
}

/**
 * D83-5: the unit gravity direction in the device frame for `deviceorientation` β, γ (degrees,
 * W3C Z-X'-Y''): `(cos β · sin γ, sin β, cos β · cos γ)`. Its first two components are the
 * natural-orientation screen axes (x right, y down); a flat phone gives (0, 0, 1).
 */
export function deviceDirection(beta: number, gamma: number): [number, number, number] {
  const b = beta * DEG;
  const g = gamma * DEG;
  return [Math.cos(b) * Math.sin(g), Math.sin(b), Math.cos(b) * Math.cos(g)];
}

/**
 * D83-5: the screen-plane gravity (CSS axes) of a device direction, rotated by the screen angle θ
 * (degrees): `gx = s · (px · cos θ + py · sin θ)`, `gy = s · (−px · sin θ + py · cos θ)`. The
 * projection (not a normalised direction) gives a flat phone no gravity and damps the γ jitter
 * near β = ±90°.
 */
export function screenGravity(dir: readonly [number, number, number], angleDeg: number, strength: number): [number, number] {
  const t = angleDeg * DEG;
  const c = Math.cos(t);
  const s = Math.sin(t);
  const [px, py] = dir;
  return [strength * (px * c + py * s) + 0, strength * (-px * s + py * c) + 0];
}

      this.seedPending = true;
      return;

    this.fixed = fixedGravity(this.gravity.vector, this.gravity.strength);

      this.seedPending = true;
      this.held = null;

    if (reducedMotion) {
      this.wasReduced = true;
      return { gx: 0, gy: 0, seed: false };
    }
    const [gx, gy] = this.current();
    const seed = this.seedPending || this.wasReduced;
    this.seedPending = false;
    this.wasReduced = false;

### Gravity and tilt (Ward 083)

- **Engine (Rust, `gravity.rs`, D83-1, D83-2):** a per-core low-pass `g_lp` (f64, `τ = 0.5 s`, advanced once per fixed step); each fixed step hands the grid `GRAVITY_SCALE · (g − g_lp)` (1.5, clamped to `GRAVITY_CLAMP_PX_S2` 2000 along its direction) through `Grid::set_body_accel`, and `update_velocities` adds it to the cells with mass after momentum → velocity, before the walls and the CFL cap. Below `GRAVITY_SNAP_PX_S2` (0.5) the high-pass snaps to exactly 0 (`g_lp = g`), so ≈ 8τ after a change the engine is bit-identical to one without gravity. Input is sanitised (NaN/Inf → 0, ±1e5). Under reduced motion `tick` seeds the low-pass every call. Parked particles skip the grid; the home spring is unchanged (a subtle lean, ≈ 6.4 px for a 90° tilt, rest within 3 s).
- **Sources (TS, `gravity.ts`, D83-3 … D83-5):** `GravityInput` (one per instance) gives every frame's `tick` its gravity: `none` 0; `fixed` `normalize(vector) · strength` (a zero vector is none); `orientation` the device direction from `deviceorientation` β, γ, `(cos β · sin γ, sin β)` rotated by `screen.orientation.angle` (else `window.orientation`, else 0), times `strength`, held until a reading turns it by more than `ORIENTATION_DEAD_BAND_DEG` (2), with the listener only while the source is `orientation` (removed on a switch and on `destroy`). Under reduced motion it hands 0. It asks for `core.seed_gravity` before the tick at `create()`, after a source switch, on the first orientation reading and on the first frame after reduced motion, so none of them sloshes (D83-4).
- **API (D83-3):** `setGravity(partial)` reads each own key once (`mergeGravity`), validates the merge like create()'s `gravity` (TypeError, state unchanged) and hands it to the runtime; a change within a source acts on the next frame.
