**Design resolutions this plan makes (within the approved decisions; presented with the plan):**
1. **The canvas's z-index is the instance's mode.** `remountLiquidCanvas` copies the old canvas's z-index (an `'auto'` fallback or a device-loss rebuild keeps the mode), and `fallBack()` writes `CANVAS_Z_FALLBACK` on the current canvas. No second state can drift from it.
2. **Two instances in different modes share one sheet and one decoration.** The sheet text is the same in both modes (the D7 rules key on the attribute); the class decoration stays one refcount per element; the stacking attribute is a second refcount per element, held only by fallback instances, restored to the author's value on the last release. An element observed by an instance under the page and by a fallback instance carries the attribute while the fallback instance observes it (vitest 14).
3. **The `create()` check in body mode is `<body>` only** (the canvas's ancestor chain: `<html>` never counts, its background is the root canvas). In container mode it is the stacking-context test; the container's own background paints below a `z-index: -1` canvas inside it, so the `observe()` walk stops at the container.
4. **"Within 80 px of a viewport edge"** is per axis: the rect's low edge `< 80` px from 0, or its high edge `< 80` px from the extent. A rect near both edges of one axis keeps that component (nothing is inward). An element entirely beyond an edge counts as near it (it is parked when farther than the margin, W81). Until TS calls `set_viewport` the viewport is unknown and nothing mirrors, so every existing Rust test is unchanged.
5. **`set_viewport` follows the canvas size.** `sendViewport(w, h)` sends the same `w × h` (CSS px = buffer px) the canvas gets: once in `buildRuntime` before the reduced-motion setup (so the create-time calls still end with `set_reduced_motion`, which `runtime.test.ts` pins), then from `resizeCanvas()` (window `resize`, the container's ResizeObserver, a DPR change, a device-loss rebuild) only when the size changed; never after a failed frame.
6. **The page probes read screenshots, not the canvas.** Whether liquid paints over or under text shows only in the composited page. `e2e/under-page.ts` takes a screenshot of the text box, hides every liquid canvas for a reference screenshot of the same manual-clock frame, and counts ink pixels (≥ 95 % of the box's darkest distance from its background; antialiased edges excluded) that changed by more than 60. A `changed` count proves the liquid reached the box, so the probe is never vacuous.
7. **No baseline moves, none is added** (W82.0 Q1e: 13/13 pixel-identical with the canvas at −1; Q2: the acceptance cell stays on the 2 px floor; Q3: step-6 diff 0). W82.4 runs the Docker Canvas2D suite without `--update-snapshots`.

```rust
//! W82 (D82-5): the viewport in buffer px, for the shake's edge mirror.
//!
//! Rust stays DOM-blind: TS passes the visible window's size (`innerWidth × innerHeight` in body
//! mode, the container's client box in container mode) through `FluidCore::set_viewport(w, h)`,
//! at `create()` and from every `resizeCanvas()`. Buffer space starts at the viewport's top-left
//! corner, so the viewport is `[0, w] × [0, h]`. The world stays `max(screen, inner)` (W81).
//!
//! The rule: when an element's home rect lies within `EDGE_MIRROR_PX` of a viewport edge, the
//! outward component of its shake direction is mirrored, so it sloshes inward instead of being
//! clipped flat at the edge (W82.0 Q3: the landing's dark card and "Sign in"). An element farther
//! than `EDGE_MIRROR_PX` from every edge keeps its direction bit for bit.

use super::elements::Rect;
use super::grid::WORLD_MAX_PX;

/// D82-5: an edge this close to the home rect mirrors the shake's outward component (px). It is
/// above the measured shake travel at strength 1 (69 px, W82.0 Q3).
pub const EDGE_MIRROR_PX: f32 = 80.0;

/// The viewport extent per axis in buffer px; 0 = unknown (no mirror on that axis).
#[derive(Clone, Copy, Debug, PartialEq)]
pub struct Viewport {
    pub w: f32,
    pub h: f32,
}

impl Viewport {
    /// Before the first `set_viewport`: no mirror at all (a core driven without TS, e.g. the Rust
    /// tests, behaves exactly as before W82).
    pub const UNKNOWN: Viewport = Viewport { w: 0.0, h: 0.0 };

    /// Per axis: a finite, positive extent is kept, clamped to `WORLD_MAX_PX`; NaN, ±Inf, 0 and
    /// negative values give 0 (unknown).
    pub fn sanitized(w: f32, h: f32) -> Viewport {
        let _ = (w, h, WORLD_MAX_PX); // W82.1 red stub: W82.2 keeps the finite, positive extents
        Viewport::UNKNOWN
    }
}

/// One axis: `d` is the direction component, `[lo, hi]` the rect's extent, `extent` the
/// viewport's. Near the low edge a negative `d` flips, near the high edge a positive one; a rect
/// near both edges of an axis (nothing is inward), an unknown extent or a non-finite rect keeps `d`.
fn mirror_axis(d: f32, lo: f32, hi: f32, extent: f32) -> f32 {
    let _ = (lo, hi, extent); // W82.1 red stub: W82.2 mirrors the outward component
    d
}

/// D82-5: the shake direction `(dx, dy)` of an element whose home rect is `r` (buffer px), with
/// its outward components mirrored near the viewport's edges.
pub fn mirror_outward(dx: f32, dy: f32, r: &Rect, vp: Viewport) -> (f32, f32) {
    (
        mirror_axis(dx, r.x, r.x + r.w, vp.w),
        mirror_axis(dy, r.y, r.y + r.h, vp.h),
    )
}
```

```ts
/**
 * W82 (D82-1, D82-2, D82-5): page-pixel probes for "under the page". The canvas probes of e2e/lace.ts
 * read the liquid canvas only; whether the liquid paints over or under page text shows only in a
 * screenshot of the page. A WebGPU canvas is composited into page screenshots like any other.
 *
 * Ink probe (W82.0 Q1a): a screenshot of a text box with the liquid, and a reference screenshot of
 * the same frame with every liquid canvas hidden (`visibility: hidden`, restored at once; no frame
 * runs in between under the manual clock). Ink pixels are the reference pixels whose |Δrgb|₁ from
 * the box's background (its top-left pixel) is at least INK_FRACTION of the box's largest; an ink
 * pixel is covered when the liquid changed it by more than COVER_L1. With the canvas under the page
 * the glyphs are drawn over the liquid and no fully inked pixel changes; at z-index 0 the liquid
 * hides whole letters (W82.0: 86 covered on the landing lede under a strength-2 splash, 137 under a
 * strength-2 shake).
 */
import type { Page } from "@playwright/test";
import type { ClientRect } from "./lace";

/** A pixel is ink when its distance from the background is at least this share of the box's largest (antialiased edges excluded). */
export const INK_FRACTION = 0.95;
/** |Δrgb|₁ above which the liquid changed a pixel (W82.0 Q1a). */
export const COVER_L1 = 60;
/** Covered ink pixels allowed: the canvas under the page covers none. */
export const MAX_COVERED_INK_PX = 0;

export interface InkProbe {
  /** Ink pixels of the box in the reference. */
  ink: number;
  /** Ink pixels the liquid changed. */
  covered: number;
  /** Pixels of the box the liquid changed (ink or not): > 0 means the liquid reached the box. */
  changed: number;
}

async function decodeAndCompare(page: Page, live: Buffer, ref: Buffer, inkFraction: number, coverL1: number): Promise<InkProbe> {
  return page.evaluate(
    async ([a, b, frac, cover]) => {
      const load = async (b64: string): Promise<ImageData> => {
        const blob = await (await fetch(`data:image/png;base64,${b64}`)).blob();
        const bmp = await createImageBitmap(blob);
        const c = new OffscreenCanvas(bmp.width, bmp.height);
        const ctx = c.getContext("2d");
        if (!ctx) throw new Error("W82: no 2d context for the ink probe");
        ctx.drawImage(bmp, 0, 0);
        return ctx.getImageData(0, 0, bmp.width, bmp.height);
      };
      const L = await load(a);
      const R = await load(b);
      const n = Math.min(L.data.length, R.data.length);
      const bg = [R.data[0], R.data[1], R.data[2]];
      const dist = (d: Uint8ClampedArray, o: number, c: number[]): number =>
        Math.abs(d[o] - c[0]) + Math.abs(d[o + 1] - c[1]) + Math.abs(d[o + 2] - c[2]);
      let max = 0;
      for (let o = 0; o < n; o += 4) max = Math.max(max, dist(R.data, o, bg));
      let ink = 0;
      let covered = 0;
      let changed = 0;
      for (let o = 0; o < n; o += 4) {
        const moved = dist(L.data, o, [R.data[o], R.data[o + 1], R.data[o + 2]]) > cover;
        if (moved) changed += 1;
        if (max === 0 || dist(R.data, o, bg) < frac * max) continue;
        ink += 1;
        if (moved) covered += 1;
      }
      return { ink, covered, changed };
    },
    [live.toString("base64"), ref.toString("base64"), inkFraction, coverL1] as const,
  );
}

/** W82.0 Q1a ink probe over `selector`'s bounding box at the current frame (see the module doc). */
export async function inkCovered(page: Page, selector: string, inkFraction: number = INK_FRACTION, coverL1: number = COVER_L1): Promise<InkProbe> {
  const box = await page.locator(selector).boundingBox();
  if (!box) throw new Error(`W82: ${selector} has no box`);
  const clip = { x: Math.floor(box.x), y: Math.floor(box.y), width: Math.ceil(box.width), height: Math.ceil(box.height) };
  const live = await page.screenshot({ clip });
  await page.evaluate(() => {
    for (const c of document.querySelectorAll<HTMLCanvasElement>("canvas.liquid-canvas")) c.style.visibility = "hidden";
  });
  const ref = await page.screenshot({ clip });
  await page.evaluate(() => {
    for (const c of document.querySelectorAll<HTMLCanvasElement>("canvas.liquid-canvas")) c.style.visibility = "";
  });
  return decodeAndCompare(page, live, ref, inkFraction, coverL1);
}

/** Page-screenshot pixels inside `rect` within |Δrgb|₁ < 60 of `rgb` (the liquid seen on the page, whatever paints over it). */
export async function pagePixelsOf(page: Page, rect: ClientRect, rgb: readonly [number, number, number]): Promise<number> {
  const clip = { x: Math.floor(rect.x), y: Math.floor(rect.y), width: Math.ceil(rect.width), height: Math.ceil(rect.height) };
  const shot = await page.screenshot({ clip });
  return page.evaluate(
    async ([b64, c]) => {
      const blob = await (await fetch(`data:image/png;base64,${b64}`)).blob();
      const bmp = await createImageBitmap(blob);
      const off = new OffscreenCanvas(bmp.width, bmp.height);
      const ctx = off.getContext("2d");
      if (!ctx) throw new Error("W82: no 2d context for the page pixels");
      ctx.drawImage(bmp, 0, 0);
      const d = ctx.getImageData(0, 0, bmp.width, bmp.height).data;
      let n = 0;
      for (let o = 0; o < d.length; o += 4) if (Math.abs(d[o] - c[0]) + Math.abs(d[o + 1] - c[1]) + Math.abs(d[o + 2] - c[2]) < 60) n++;
      return n;
    },
    [shot.toString("base64"), rgb] as const,
  );
}

/**
 * W82 (D82-5): liquid canvas pixels of colour `rgb` (alpha > 128, |Δrgb|₁ < 60) on the canvas's
 * outermost column or row on `edge`, from `__liquidTest.pixels()` (the frame of the last advance()).
 */
export async function edgePixels(page: Page, rgb: readonly [number, number, number], edge: "right" | "top"): Promise<number> {
  return page.evaluate(
    ([c, e]) => {
      const { width: W, height: H, data } = window.__liquidTest!.pixels();
      const at = (x: number, y: number): boolean => {
        const o = (y * W + x) * 4;
        return data[o + 3] > 128 && Math.abs(data[o] - c[0]) + Math.abs(data[o + 1] - c[1]) + Math.abs(data[o + 2] - c[2]) < 60;
      };
      let n = 0;
      if (e === "right") for (let y = 0; y < H; y++) n += at(W - 1, y) ? 1 : 0;
      else for (let x = 0; x < W; x++) n += at(x, 0) ? 1 : 0;
      return n;
    },
    [rgb, edge] as const,
  );
}
```

```ts
/** Probes `selector` at every PROBE_FRAMES frame after `act` ran; returns the worst cover and the most changed pixels. */
```

```ts
/** The worst ink probe over `selector` at W82_PROBE_FRAMES after `act`, and the most liquid seen behind it. */
async function w82Probe(page: Page, selector: string, act: () => Promise<unknown>, step: (n: number) => Promise<unknown>): Promise<{ covered: number; frame: number; reached: number }> {
  await act();
  let at = 0;
  let covered = -1;
  let frame = 0;
  let reached = 0;
  for (const f of W82_PROBE_FRAMES) {
    await step(f - at);
    at = f;
    const p = await inkCovered(page, selector);
    reached = Math.max(reached, p.changed);
    if (p.covered > covered) {
      covered = p.covered;
      frame = f;
    }
  }
  return { covered, frame, reached };
}
```

```ts
 * W82 (D82-1, D82-2): may the canvas sit under the page (`z-index: -1`)?
 *
 * Body mode: the canvas sits at `z-index: -1` in the root stacking context, so every page box and
 * its text paint above escaped liquid. Any ancestor box between an observed element and the root

 * `parentDisplay`) forms a stacking context (CSS 2.2 §9.9.1, Positioned Layout, Compositing):
 * fixed or sticky; absolute or relative with a `z-index`; a flex or grid item with a `z-index`;
 * opacity < 1; transform (or translate, rotate, scale), filter, perspective, clip-path, mask,
 * backdrop-filter; `isolation:
 * isolate`; a blend mode; `will-change` naming one of those; `contain` layout/paint/strict/content;
 * a size container.
 */
export function formsStackingContext(cs: StackingStyle, parentDisplay = ""): boolean {
  const position = val(cs.position);
  const z = val(cs.zIndex);
  const hasZ = z !== "" && z !== "auto";
  if (position === "fixed" || position === "sticky") return true;
  if (hasZ && (position === "absolute" || position === "relative")) return true;
  if (hasZ && /^(inline-)?(flex|grid)$/.test(val(parentDisplay))) return true;
  const opacity = Number.parseFloat(val(cs.opacity));
  if (Number.isFinite(opacity) && opacity < 1) return true;
  for (const v of [cs.transform, cs.translate, cs.rotate, cs.scale, cs.filter, cs.perspective, cs.clipPath, cs.maskImage, cs.backdropFilter]) if (!isNone(v)) return true;

  if (blend !== "" && blend !== "normal") return true;
  if (val(cs.willChange).split(",").some((t) => WILL_CHANGE_STACKING.has(t.trim()))) return true;
  if (/\b(layout|paint|strict|content)\b/.test(val(cs.contain))) return true;

/** A computed colour with alpha 0: "", "transparent", `rgba(…, 0)`, `rgb(… / 0)`, `oklch(… / 0%)`, … */
export function isTransparentColor(raw: string | undefined): boolean {
  const s = val(raw);
  if (s === "" || s === "transparent") return true;
  const m = /^[a-z-]+\((.*)\)$/.exec(s);
  if (!m) return false;
  const inner = m[1] ?? "";
  let alpha: string | undefined;
  if (inner.includes("/")) alpha = inner.slice(inner.lastIndexOf("/") + 1);
  else {
    const parts = inner.split(",");
    if (parts.length === 4) alpha = parts[3];
  }
  return alpha !== undefined && /^0*(\.0*)?%?$/.test(alpha.trim()) && /0/.test(alpha);
}

 * D82-2: the first box from `from` up to (not including) `stop` and `<html>` whose opaque
 * background would paint over a `z-index: -1` canvas, or null. `<body>` counts only when `<html>`
 * has its own background; an observed element (`.liquid-element`, its background is the liquid)
 * never counts.
 */
export function opaqueAncestor(from: Element | null, stop: Element | null): Element | null {
  const root = from?.ownerDocument.documentElement ?? null;
  for (let el = from; el !== null && el !== stop && el !== root; el = el.parentElement) {
    if (el.classList.contains(ELEMENT_CLASS)) continue;
    const cs = computed(el);
    if (cs === null || !hasOwnBackground(cs)) continue;
    if (el === el.ownerDocument.body) {
      const html = root ? computed(root) : null;
      if (html === null || !hasOwnBackground(html)) continue; // body's background propagates to the root
    }
    return el;
  }
  return null;
}
```

````markdown
---
"liquiddom": minor

The liquid goes under the page. The liquid canvas now sits at `z-index: -1`, so splashed or shaken liquid passes under the page's own text and boxes instead of over them, and observed elements no longer get `position: relative; z-index: 1` (their author dropdowns and overlays now show above them). If the page cannot take the canvas underneath — `<html>` and `<body>` both have a background, a wrapper or `<main>` around an observed element has an opaque background, or the `container` is not a stacking context (give it `isolation: isolate`) — liquiddom logs one `console.warn` naming the element and keeps the previous behaviour (`z-index: 0`) for that instance. Under a shake, an element close to a window edge now sloshes inward instead of being cut off at the edge. The Canvas2D renderer draws a smoother edge while the liquid moves on pages with large elements (at some extra render cost there).
````
