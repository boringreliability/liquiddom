**Snapshot** (`element-registry.ts`, 374 lines)

**Paint** (`renderers/frame.ts:13-34`)

- Spec §3 adds `shadows: readonly ShadowLayer[]`.

**Canvas2D** (`renderers/fluid-canvas2d.ts`, 189 lines; `density-grid.ts`, 209 lines)
- `splatMoving` splats **every** moving element into one shared density grid (`:123-153`).
- `drawDensity` does one `putImageData` into an offscreen canvas, then one `drawImage` (`:155-164`).
- `drawResting` draws a `roundRect` per element at `restAlpha` (`:166-189`).
- A per-element mask is therefore new work per shadowed element. Spike Q1 measures that cost.

**WebGPU** (`renderers/webgpu/webgpu-renderer.ts`, 1245 lines; `shaders.ts`, 422 lines)
- Passes, in order: `splat` (`:585`), the text pass while text moves (`:595`), then `screen` (`:602`).
- The screen pass draws the composite, the rest SDF and the text composite.
- T0 is half resolution by default (`t0Scale` 0.5).
