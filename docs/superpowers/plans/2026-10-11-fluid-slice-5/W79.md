**Design resolutions this plan makes (stated in the D79 Proposal texts so the gate covers them):**
1. **One `rg16float` target with `min` on `(id, −id)` instead of two `r16float` targets with `min`/`max`** (D79-1). A WebGPU blend state has one `color` operation for all channels of a target, and `min`/`max` require both factors to be `"one"`; `r16float`, `rg16float` and `rgba16float` are blendable in core WebGPU (`r32float` needs `float32-blendable`). Storing `−id` in g turns the max into a min, so one target and one blend state do both. 4096 (the clear value) is exact in f16 and above every slot id (`MAX_ELEMENTS_MAX` 256).
2. **The composite reads the four texels its bilinear T1 sample mixes** (`textureGather`), not one texel (D79-1). A pixel shows text from the texels its sample interpolates; the rule must hold for all four, so it is conservative by up to one texel. The id target needs no filtering.
3. **The id marks the liquid, not the glyphs** (D79-1): every covered fragment writes its id, torn or not and wherever the glyph is transparent, exactly the fragments that add Σw — so "two ids" means "two elements' text-carrying liquids overlap here". An element without drawn atlas text never enters the T1 pass and never drops another element's text.
4. **The merge slip is per element and ends at rest** (D79-2 option B). This plan's validation measured option B equal to the spike's global setting for the merge, to the third decimal, while leaving every run without a drag bit-identical (all 181 existing Rust tests pass unchanged; option A fails 5).
5. **The card splash is the perf reference** (D79-3): a splash on "Splash" moves a 655-particle pill, the merge moves the 6035-particle card; their ratio would measure the card, not W79.
6. **Neighbour overlap uses the engine's own home rects** (offset and hover swell included, open intervals), so Rust stays DOM-blind and the rule needs no new slot or FFI call. The drag from Merge's centre to the card's centre passes over Split (within 16 px during ramp frames 1–4): Split is softened briefly and re-forms during the hold.

### D79-1: Labels never overlap: a per-texel element-id target in the text pass (mechanism a)
Proposal: displacement + fade (brainstorm, Dennis 2026-10-11). The physics moves the card's liquid and text out of the dragged liquid's way (D79-2); where two elements' liquids still mix, the text drops. Mechanism (a): the WebGPU text pass gets a third target, T1id, one `rg16float` texture at T1's size, cleared to 4096 and blended with `min` on both channels; every text fragment the kernel covers (torn or not, glyph or transparent: exactly the fragments that add Σw) writes `(id, −id)` of its element, so per texel r is the smallest and −g the largest element id whose text-carrying liquid reached it. One target, not two `r16float` targets with `min` and `max`: a WebGPU blend state has a single `color` operation for all channels of a target, and `min`/`max` require both factors to be `"one"`; storing −id turns the max into a min. `r16float`, `rg16float` and `rgba16float` are blendable in core WebGPU (`r32float` needs `float32-blendable`); 4096 and every slot id (≤ 255) are exact in f16. The text composite gathers the four T1id texels its bilinear T1 sample mixes (`textureGather`) and gives the text coverage 0 where the smallest id is below the largest. Mechanism (b) (Rust flags a particle "foreign" from a per-substep owner-mass pass) is not built: +0.46 ms CPU per tick (+13 %) measured in W78.0, a coarse cell-majority flag that would need hysteresis, and no per-pixel guarantee.
Consequence: Under WebGPU no pixel carries text of two elements; where Merge's and the card's liquids mix, neither shows text (the mixed area is text-free, and two text-carrying liquids that only touch lose their text in a seam about one texel wide); away from the mix both texts show. Cost: one more 4-byte texel per backing pixel (≈ 4 MB at 1280 × 800, DPR 1) and one more blended write per text fragment, estimated ≤ +0.27 ms GPU per frame and only while text moves (W78.0 estimate, not measured; logged, not gated, D72-4). Only elements whose atlas text is drawn take part: a textless element's liquid never drops another element's text, and an element whose atlas text is not ready keeps its DOM text (rare: the atlas is built at observe). Canvas2D is unchanged: it draws no liquid text and hides the dragged label (W78).

//! scenario tests drive the real `FluidCore` over the acceptance layout (W78's `drag_tests`
//! layout: three buttons 140×48 r24 at y 260, card 320×180 r16 at y 340, 1280×800). "Merge" is
//! dragged centre to centre into the card: its offset ramps to (−164, +146) px over 10 frames,
//! holds 90 frames (D79-4) and is released. Shared MPM liquid couples neighbours (W78 lesson):
//! no test here demands bit-identical motion next to a pushed neighbour.

use super::api::FluidCore;
use super::elements::{Elements, Rect, rects_overlap};
use super::interaction::{
    DRAG_STIFFNESS_CAP, NEIGHBOUR_MARGIN_PX, NEIGHBOUR_STIFFNESS_CAP, hold_dragged,

use super::layout::{
    ELEMENT_STRIDE, INTERACTION_DRAGGED, INTERACTION_IDLE, ST_REST_ALPHA, ST_S, STATE_STRIDE,
};
use super::solver::{
    MERGE_SLIP_MAX_PX_S, MERGE_SLIP_RATE_PER_S, SLIP_MAX_PX_S, SLIP_RATE_PER_S, slip_velocity,
    slip_velocity_at,

const DT: f32 = 1.0 / 60.0;

/// x, y, w, h, radius in px.
type Bx = (f32, f32, f32, f32, f32);
const SPLASH: Bx = (406.0, 260.0, 140.0, 48.0, 24.0);
const SPLIT: Bx = (570.0, 260.0, 140.0, 48.0, 24.0);
const MERGE: Bx = (734.0, 260.0, 140.0, 48.0, 24.0);
const CARD: Bx = (480.0, 340.0, 320.0, 180.0, 16.0);
const LAYOUT: [Bx; 4] = [SPLASH, SPLIT, MERGE, CARD];
const SPLASH_ID: usize = 0;
const SPLIT_ID: usize = 1;
const MERGE_ID: usize = 2;
const CARD_ID: usize = 3;
/// Σ rounded-rect areas of the layout, as in drag_tests.
const AREA_HINT_PX2: f32 = 76_057.0;
const MAX_ELEMENT_H_PX: f32 = 180.0;
/// Merge's centre (804, 284) to the card's centre (640, 430), as the e2e drags it.
const TO_CARD: (f32, f32) = (-164.0, 146.0);
const RAMP_FRAMES: u32 = 10;

fn element(b: Bx, interaction: f32, dx: f32, dy: f32) -> [f32; ELEMENT_STRIDE] {
    [
        b.0,
        b.1,
        b.2,
        b.3,
        b.4,
        interaction,
        dx,
        dy,
        f32::NAN,
        f32::NAN,
    ]
}

fn scene(seed: u32) -> FluidCore {
    let mut core = FluidCore::new(
        8000,
        32,
        1280.0,
        800.0,
        AREA_HINT_PX2,
        MAX_ELEMENT_H_PX,
        seed,
    );
    for (id, b) in LAYOUT.iter().enumerate() {
        core.write_element(id, element(*b, INTERACTION_IDLE, 0.0, 0.0));
    }
    core.redistribute();
    core
}

fn idle(core: &mut FluidCore, frames: u32) {
    for _ in 0..frames {
        let _ = core.tick(DT, 0.0, 0.0, 0.0, 0.0, false, 0.0, 0.0);
    }
}

/// Frame `f` (1-based) of the drag: the offset ramps linearly to TO_CARD, then holds.
fn drag_frame(core: &mut FluidCore, f: u32) {
    let k = f.min(RAMP_FRAMES) as f32 / RAMP_FRAMES as f32;
    core.write_element(
        MERGE_ID,
        element(MERGE, INTERACTION_DRAGGED, TO_CARD.0 * k, TO_CARD.1 * k),
    );
    idle(core, 1);
}

fn release(core: &mut FluidCore) {
    core.write_element(MERGE_ID, element(MERGE, INTERACTION_IDLE, 0.0, 0.0));
}

fn s_of(core: &FluidCore, id: usize) -> f32 {
    core.state(id).get(ST_S).copied().unwrap_or(f32::NAN)
}

fn rest_alpha(core: &FluidCore, id: usize) -> f32 {
    core.state(id)
        .get(ST_REST_ALPHA)
        .copied()
        .unwrap_or(f32::NAN)
}

fn all_at_rest(core: &FluidCore) -> bool {
    (0..LAYOUT.len()).all(|id| rest_alpha(core, id) >= 1.0)
}

/// `(x, y, w, h)` of a box, optionally moved.
fn rect_of(b: Bx, dx: f32, dy: f32) -> (f32, f32, f32, f32) {
    (b.0 + dx, b.1 + dy, b.2, b.3)
}

fn inside(p: (f32, f32), r: (f32, f32, f32, f32), inset: f32) -> bool {
    p.0 >= r.0 + inset && p.0 <= r.0 + r.2 - inset && p.1 >= r.1 + inset && p.1 <= r.1 + r.3 - inset
}

fn rect(x: f32, y: f32, w: f32, h: f32) -> Rect {
    Rect { x, y, w, h, r: 0.0 }
}

fn elements_with(slots: &[[f32; ELEMENT_STRIDE]]) -> Elements {
    let mut e = Elements::new(slots.len().max(1));
    for (id, s) in slots.iter().enumerate() {
        e.buf[id * ELEMENT_STRIDE..(id + 1) * ELEMENT_STRIDE].copy_from_slice(s);
        e.state[id * STATE_STRIDE + ST_REST_ALPHA] = 1.0;
    }
    e
}

        let s = s_of(&core, CARD_ID);

        }

        }
    }

}

/**
 * W79 (D79-1): the acceptance hook's reading of the WebGPU text id target (test scaffolding, like
 * render-counting-clock.ts; never part of the package). A capture holds the raw rg16float texels
 * of one frame: r = the smallest element id of every text splat that reached the texel, g = minus
 * the largest, both `empty` where none did. A texel is "mixed" when its smallest id is below its
 * largest: text splats of two elements met there, and no canvas text may show on it. Structural
 * types only, so the scene loads even before the renderer exports its own (W79.1 red).
 */
export interface TextIdCaptureLike {
  readonly textPass: boolean;
  readonly width: number;
  readonly height: number;
  readonly bytesPerRow: number;
  readonly empty: number;
  readonly data: Uint16Array;
}

export interface PixelsLike {
  readonly width: number;
  readonly height: number;
  readonly data: Uint8ClampedArray;
}

export interface TextIdReport {
  textPass: boolean;
  /** Texels where the smallest id is below the largest. */
  mixed: number;
  /** Canvas text pixels (every channel and alpha ≥ textMin) on mixed texels. */
  mixedTextPx: number;
  /** Canvas text pixels anywhere in the capture. */
  textPx: number;
  /** Every slot id seen, ascending. */
  ids: number[];
}

/** IEEE 754 half (as its 16 bits) → number. */
export function halfToFloat(h: number): number {
  const sign = h & 0x8000 ? -1 : 1;
  const exp = (h >> 10) & 0x1f;
  const frac = h & 0x3ff;
  if (exp === 0) return sign * frac * 2 ** -24;
  if (exp === 0x1f) return frac === 0 ? sign * Infinity : Number.NaN;
  return sign * (1 + frac / 1024) * 2 ** (exp - 15);
}

/** One frame's ids against the same frame's pixels (same size: T1 is at 1× the backing). */
export function summarizeTextIds(c: TextIdCaptureLike, px: PixelsLike, textMin: number): TextIdReport {
  const report: TextIdReport = { textPass: c.textPass, mixed: 0, mixedTextPx: 0, textPx: 0, ids: [] };
  if (!c.textPass) return report;
  if (c.width !== px.width || c.height !== px.height) {
    throw new Error(`text-id-report: capture ${c.width}x${c.height} vs pixels ${px.width}x${px.height}`);
  }
  const seen = new Set<number>();
  const row = c.bytesPerRow / 2;
  for (let y = 0; y < c.height; y++) {
    for (let x = 0; x < c.width; x++) {
      const o = (y * px.width + x) * 4;
      const d = px.data;
      const text = d[o + 3] >= textMin && d[o] >= textMin && d[o + 1] >= textMin && d[o + 2] >= textMin;
      if (text) report.textPx++;
      const lo = halfToFloat(c.data[y * row + 2 * x]);
      const hi = -halfToFloat(c.data[y * row + 2 * x + 1]);
      if (!(lo < c.empty)) continue;
      seen.add(lo);
      seen.add(hi);
      if (lo + 0.5 < hi) {
        report.mixed++;
        if (text) report.mixedTextPx++;
      }
    }
  }
  report.ids = [...seen].sort((a, b) => a - b);
  return report;
}
