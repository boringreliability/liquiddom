**Goal:** a drag gesture in TypeScript, three engine rules in Rust (hold `s ≤ 0.5`, home velocity with the offset, pointer field skips the dragged liquid) and a Canvas2D label class, so step 5's "drag away, release, crawl home" works in both renderers without moving the DOM.

**Architecture:** `DragTracker` (new `drag-tracker.ts`, one per instance) listens for `pointerdown` on each observed element; a mouse or pen press with the primary button becomes a drag once the pointer is more than 4 px from the down point, and only then does it call `setPointerCapture`. While dragging, `active = {el, dx, dy}`. `ElementRegistry.sync()` reads it every frame and writes slot 5 = `DRAGGED` (beating hover and focus) and slots 6–7 = `dx, dy` for that element, 0 for every other. The runtime calls `dragTracker.frame()` before `registry.sync()` (a detached element cancels) and cancels on reduced motion, a lost device, a failed frame, `unobserve()` and `destroy()`. The click that ends a drag is swallowed once by a window capture-phase listener. Rust: `interaction::hold_dragged` runs `damage(id, 0.5)` for every dragged element in every substep after `update_stiffness`, so `s ≤ 0.5` and `restAlpha` stays 0; `Elements::update_velocities` adds the offset delta while dragged (none on the release frame); `ElRow.dragged` makes the P2G pointer term skip the dragged element's particles. `homeRectInto` (TS) and `home_rect` (Rust) already apply `home_dx/dy`, so targets and the rest contour follow the displaced home with no change. Canvas2D: `away-toggle.ts` (the `text-toggle.ts`/`halo-toggle.ts` pattern) holds `liquid-away` per element while it is dragged and after release until `restAlpha = 1`; the halo is suppressed for held elements.

**Design resolutions this plan makes (stated in the D78 Proposal texts so the gate covers them):**
1. **Capture at the threshold, not at `pointerdown`** (D78-2). The spec row reads "pointerdown with pointer capture + > 4 px movement". Capturing at `pointerdown` would retarget every plain click on an observed element (a link inside the card would no longer receive its click), so the tracker captures when the drag starts; before that it follows the pointer through document listeners.
2. **The click is swallowed in `drag-tracker.ts`, not `input.ts`** (D78-6). A window capture-phase listener (`stopImmediatePropagation` + `preventDefault`) runs before every other listener, so it stops the splash, the author's handlers and a second instance's listeners alike; `SplashInput` (`input.ts:27-64`) is unchanged. A cancel after the threshold also arms the swallow until that press's `pointerup`.
3. **The release frame adds no home velocity** (D78-3). On release TS writes slot 5 → 0 and the offset → 0 in one frame; counting that jump would put a −offset/dt spike (≈ −9800 px/s for a 164 px drag) into the spring damping for one tick. The offset counts only while slot 5 is `DRAGGED`.
4. **A new class `liquid-away`** (D78-1). The design names "the `liquid-text` rule"; reusing the `liquid-text` class itself would break D74-6 ("Canvas2D never sets liquid-text", pinned by two e2e tests). The new class carries the identical declarations and its own refcount; `OWN_CLASSES` gains it (an approved-test change).
5. **The hold runs every substep** (D78-3). Applied once per tick, `update_stiffness` would let `s` recover to ≈ 0.51 within the 8 substeps; the design's "`s ≤ 0.5` while dragged" holds at every substep only when the hold follows each `update_stiffness`.
6. **A lost release cancels.** A `pointermove` of the pressed pointer with the primary button up (the `pointerup` went elsewhere) ends the press as a cancel.

```markdown
### D78-1: The label follows the liquid during a drag
Proposal: WebGPU keeps slice 4's atlas text on the liquid (`liquid-text` while restAlpha < 1). Canvas2D draws no liquid text, so while an element is dragged, and after a release until its restAlpha is 1, the runtime sets a new class `liquid-away` that hides its DOM glyphs with the `liquid-text` declarations (`-webkit-text-fill-color: transparent`, `text-decoration-color: transparent`, `text-shadow: none`; never `color`, so the a11y tree, focus and the colour snapshot are untouched), in the `@layer liquiddom` screen + `forced-colors: none` block, so print and forced colours always show the text. A new class, because Canvas2D never sets `liquid-text` (D74-6). No halo while it is held (a halo around hidden glyphs), and a halo held by another Canvas2D instance is overridden by a `.liquid-away .liquid-halo` rule. Consequence: under Canvas2D the dragged element shows no label while away; the DOM label returns at the frame restAlpha reaches 1 (after the 120 ms rest fade), a small pop. ### D78-5: A dragged element never rests

### D78-6: The click that ends a drag is swallowed once
Proposal: after a drag that crossed the threshold, the next `click` whose target lies inside the dragged element is stopped at the window's capture phase (`stopImmediatePropagation` and `preventDefault`) and the swallow is cleared; it is also cleared in the task after the press's `pointerup` (or at the next press), so a later click splashes normally. Consequence: the author's click handlers on the dragged element (and on its ancestors) do not see the click that ends a drag: a drag is not an activation, as with native drag and drop. With two instances on one element the first instance's listener stops the click for both.

## Specification
**Values (slice design §4).** `DRAG_THRESHOLD_PX = 4` (strictly more than 4 px from the down point); `DRAG_STIFFNESS_CAP = 0.5`; re-form after release ≤ 180 frames (NORTH-STAR step 5, 3 s at 60 Hz). Interaction codes `IDLE 0, HOVER 1, FOCUSED 2, DRAGGED 3` (unchanged).

**Gesture state machine (`drag-tracker.ts`).** idle → (mouse/pen primary `pointerdown` on an observed element, not reduced motion, no press live) → pressed → (move > 4 px) → dragging [capture, `lostpointercapture` listener] → (`pointerup`: release | `pointercancel`, `blur`, `Escape`, `lostpointercapture`, move with the button up, `detach`, `cancel()`, `frame()` on a detached element, `destroy`: cancel) → idle. A pressed (below-threshold) press ends silently. `onEnd(el, how)` fires only for a press that was dragging. Release arms the click swallow and clears it in the next task; cancel arms it until that press's `pointerup`; the next press clears it.

**Frame order (`runtime.ts`).** `applyDomChanges → dragTracker.frame → registry.sync (slots 0–7) → pointer sample → core.tick → atlas/paints → render → syncText → syncAway → syncHalo`.

**Engine (Rust).** Per substep: `update_stiffness(dt)` → `hold_dragged` (`damage(id, 0.5)` for each active element with slot 5 within ±0.5 of 3) → `substep_with` (pointer term skipped for particles whose element row is dragged). Per tick with steps > 0: `update_velocities(window)`: `v = (Δrect + [dragged] Δoffset) / window`, `prev_off ← offset if dragged else 0`.

**Label (Canvas2D).** `wantsAway = canvas2d ∧ ¬reducedMotion ∧ (dragged ∨ (held ∧ restAlpha < 1))`; NaN restAlpha counts as at rest. Held elements are passed to the halo sync as `suppressed`.
```

```rust
        b.2,
        b.3,
        b.4,
        interaction,
        dx,
        dy,
        f32::NAN,
        f32::NAN,
    ]
}

fn scene(seed: u32) -> FluidCore {
    let mut core = FluidCore::new(
        8000,
        32,
        1280.0,
        800.0,
        AREA_HINT_PX2,
        MAX_ELEMENT_H_PX,
        seed,
    );
    for (id, b) in LAYOUT.iter().enumerate() {
        core.write_element(id, element(*b, INTERACTION_IDLE, 0.0, 0.0));
    }
    core.redistribute();
    core
}

fn idle(core: &mut FluidCore, frames: u32) {
    for _ in 0..frames {
        let _ = core.tick(DT, 0.0, 0.0, 0.0, 0.0, false, 0.0, 0.0);
    }
}

/// Frame `f` (1-based) of the ramp: the offset grows linearly to DRAG_DY_PX, then holds.
fn ramp_dy(f: u32) -> f32 {
    DRAG_DY_PX * f.min(RAMP_FRAMES) as f32 / RAMP_FRAMES as f32
}

fn drag_merge(core: &mut FluidCore, dx: f32, dy: f32) {
    core.write_element(MERGE_ID, element(MERGE, INTERACTION_DRAGGED, dx, dy));
}

fn release_merge(core: &mut FluidCore) {
    core.write_element(MERGE_ID, element(MERGE, INTERACTION_IDLE, 0.0, 0.0));
}

fn rest_alpha(core: &FluidCore, id: usize) -> f32 {
    core.state(id)
        .get(ST_REST_ALPHA)
        .copied()
        .unwrap_or(f32::NAN)
}

fn all_at_rest(core: &FluidCore) -> bool {
    (0..LAYOUT.len()).all(|id| rest_alpha(core, id) >= 1.0)
}

fn positions(core: &FluidCore, id: usize) -> Vec<(f32, f32)> {
    core.particle_indices_of(id as u32)
        .into_iter()
        .map(|i| core.particle_px(i))
        .collect()
}

fn centroid(core: &FluidCore, id: usize) -> (f32, f32) {
    let ps = positions(core, id);
    let n = ps.len().max(1) as f32;
    let (sx, sy) = ps
        .iter()
        .fold((0.0f32, 0.0f32), |(sx, sy), &(x, y)| (sx + x, sy + y));
    (sx / n, sy / n)
}

fn elements_with(slots: &[[f32; ELEMENT_STRIDE]]) -> Elements {
    let mut e = Elements::new(slots.len().max(1));
    for (id, s) in slots.iter().enumerate() {
        e.buf[id * ELEMENT_STRIDE..(id + 1) * ELEMENT_STRIDE].copy_from_slice(s);
    }
    e
}

/// 30 idle frames, Merge displaced 150 px up (as a held drag when `dragged`, else as a stray idle
```

```ts
/** Canvas text pixels (every channel and alpha ≥ CANVAS_TEXT_MIN) inside `selector`'s client rect, shifted by `offset` (W78: a dragged home). */
async function canvasTextPixelsIn(page: Page, selector: string, offset: { dx: number; dy: number } = { dx: 0, dy: 0 }): Promise<number> {
  return page.evaluate(
    ([sel, min, dx, dy]) => {
      const img = window.__liquidTest!.pixels();
      const c = document.querySelector<HTMLCanvasElement>("canvas.liquid-canvas");
      const el = document.querySelector(sel);
      if (!c || !el) throw new Error(`W74: canvas or ${sel} missing`);
      const cr = c.getBoundingClientRect();
      const r = el.getBoundingClientRect();
      const b = { left: r.left + dx, right: r.right + dx, top: r.top + dy, bottom: r.bottom + dy };
      const sx = img.width / cr.width;
      const sy = img.height / cr.height;
      let n = 0;
      for (let py = Math.floor((b.top - cr.top) * sy); py < Math.ceil((b.bottom - cr.top) * sy); py++) {
        for (let px = Math.floor((b.left - cr.left) * sx); px < Math.ceil((b.right - cr.left) * sx); px++) {
          if (px < 0 || py < 0 || px >= img.width || py >= img.height) continue;
          const o = (py * img.width + px) * 4;
          if (img.data[o + 3] >= min && img.data[o] >= min && img.data[o + 1] >= min && img.data[o + 2] >= min) n++;
        }
      }
      return n;
    },
    [selector, CANVAS_TEXT_MIN, offset.dx, offset.dy] as const,
  );
}
```

```ts
/**
 * W78 (D78-2, D78-6): the drag gesture (spec §2 interaction table, drag row; slice-5 design §4).
 *
 * One tracker per instance. A press with `pointerType` mouse or pen, the primary button and the
 * primary pointer on an observed element (the innermost one, D67-9's rule) becomes a drag once the
 * pointer is more than DRAG_THRESHOLD_PX from the down point; only then is the pointer captured, so
 * a plain click keeps its native targets. While dragging, `active` reports the element and the
 * offset from the down point in CSS px; the registry writes it into slots 5–7 every frame.
 *
 * Release (`pointerup`) and cancel (`pointercancel`, window `blur`, `Escape`, `lostpointercapture`,
 * a move with the primary button up, detach/unobserve, cancel() for reduced motion, a lost device
 * or a failed frame, frame() for a detached element, destroy) are the same for the engine; `onEnd`
 * tells the runtime which one it was. The click that ends a drag is swallowed once at the window's
 * capture phase (before every other listener, so the splash, the author's handlers and another
 * instance's listeners all miss it); the swallow clears in the task after the pointerup, or at the
 * next press. While a press is live, `selectstart` and `dragstart` are prevented on the document.
 * The DOM, focus and hit areas never move: drag is decoration. Touch and keyboard never drag.
 */
export const DRAG_THRESHOLD_PX = 4;

export type DragEnd = "release" | "cancel";

/** The active drag: the observed element and the offset from the down point (CSS px). */
export interface ActiveDrag {
  readonly el: HTMLElement;
  readonly dx: number;
  readonly dy: number;
}

export interface DragTrackerDeps {
  /** Read live: under reduced motion a press is ignored (spec §2). */
  reducedMotion(): boolean;
  /** Called once per drag that crossed the threshold, after the tracker let go of it. */
  onEnd?(el: HTMLElement, how: DragEnd): void;
}

interface Press {
  readonly el: HTMLElement;
  readonly pointerId: number;
  readonly x0: number;
  readonly y0: number;
  dx: number;
  dy: number;
  dragging: boolean;
}

const THRESHOLD_SQ = DRAG_THRESHOLD_PX * DRAG_THRESHOLD_PX;

export class DragTracker {
  private readonly downListeners = new Map<HTMLElement, (e: PointerEvent) => void>();
  /** pointerdown events an inner observed element already took (they bubble through the outer ones). */
  private readonly handled = new WeakSet<Event>();
  private press: Press | null = null;
  private swallowEl: HTMLElement | null = null;
  private swallowTimer: ReturnType<typeof setTimeout> | null = null;
  private destroyed = false;

  constructor(
    private readonly deps: DragTrackerDeps,
    private readonly doc: Document,
    private readonly win: Window,
  ) {}

  /** Idempotent. */
  attach(el: HTMLElement): void {
    if (this.destroyed || this.downListeners.has(el)) return;
    const onDown = (e: PointerEvent): void => this.onDown(el, e);
    this.downListeners.set(el, onDown);
    el.addEventListener("pointerdown", onDown);
  }

  /** unobserve(): a press or drag on `el` cancels and its pending click swallow is dropped. */
  detach(el: HTMLElement): void {
    const onDown = this.downListeners.get(el);
    if (onDown === undefined) return;
    el.removeEventListener("pointerdown", onDown);
    this.downListeners.delete(el);
    if (this.press?.el === el) this.end("cancel");
    if (this.swallowEl === el) this.clearSwallow();
  }

  /** The drag past the threshold, or null (a press below it is not a drag). Read it within the frame. */
  get active(): ActiveDrag | null {
    const p = this.press;
    return p !== null && p.dragging ? p : null;
  }

  /** Once per frame, before registry.sync(): a pressed element that left the document cancels. */
  frame(): void {
    if (this.press !== null && !this.press.el.isConnected) this.end("cancel");
  }

  /** Reduced motion switched on, a lost device, a failed frame. */
  cancel(): void {
    if (this.press !== null) this.end("cancel");
  }

  /** Idempotent. */
  destroy(): void {
    if (this.destroyed) return;
    this.cancel();
    for (const [el, onDown] of this.downListeners) el.removeEventListener("pointerdown", onDown);
    this.downListeners.clear();
    this.clearSwallow();
    this.destroyed = true;
  }

  private onDown(el: HTMLElement, e: PointerEvent): void {
    if (this.handled.has(e)) return;
    this.handled.add(e);
    if (this.press !== null || this.deps.reducedMotion()) return;
    if (e.pointerType !== "mouse" && e.pointerType !== "pen") return; // D78-2: no touch drag in slice 5
    if (e.button !== 0 || !e.isPrimary) return;
    if (!Number.isFinite(e.clientX) || !Number.isFinite(e.clientY)) return;
    this.clearSwallow(); // a new press: a swallow left by a cancelled drag is stale
    this.press = { el, pointerId: e.pointerId, x0: e.clientX, y0: e.clientY, dx: 0, dy: 0, dragging: false };
    this.listen(true);
  }

  private readonly onMove = (e: PointerEvent): void => {
    const p = this.press;
    if (p === null || e.pointerId !== p.pointerId) return;
    if ((e.buttons & 1) === 0) {
      this.end("cancel"); // the release went elsewhere (design resolution 6)
      return;
    }
    const dx = e.clientX - p.x0;
    const dy = e.clientY - p.y0;
    if (!Number.isFinite(dx) || !Number.isFinite(dy)) return;
    p.dx = dx;
    p.dy = dy;
    if (!p.dragging && dx * dx + dy * dy > THRESHOLD_SQ) {
      p.dragging = true;
      // Captured only now (design resolution 1), so a plain click keeps its native targets.
      if (typeof p.el.setPointerCapture === "function") {
        try {
          p.el.setPointerCapture(p.pointerId);
        } catch {
          // The pointer is no longer active; the document listeners keep tracking it.
        }
      }
      p.el.addEventListener("lostpointercapture", this.onLost);
    }
  };

  private readonly onUp = (e: PointerEvent): void => {
    if (this.press !== null && e.pointerId === this.press.pointerId) this.end("release");
  };

  private readonly onPointerCancel = (e: PointerEvent): void => {
    if (this.press !== null && e.pointerId === this.press.pointerId) this.end("cancel");
  };

  private readonly onLost = (e: PointerEvent): void => {
    if (this.press !== null && this.press.dragging && e.pointerId === this.press.pointerId) this.end("cancel");
  };

  private readonly onKey = (e: KeyboardEvent): void => {
    if (e.key === "Escape") this.end("cancel");
  };

  private readonly onBlur = (): void => {
    this.end("cancel");
  };

  private readonly onSelect = (e: Event): void => {
    if (this.press !== null) e.preventDefault();
  };

  private readonly onClickCapture = (e: MouseEvent): void => {
    const el = this.swallowEl;
    const target = e.target as Node | null;
    if (el === null || target === null || typeof target.nodeType !== "number" || !el.contains(target)) return;
    e.stopImmediatePropagation();
    e.preventDefault();
    this.clearSwallow();
  };

  private readonly onUpAfterCancel = (): void => {
    this.scheduleClear();
  };

  /** Document and window listeners exist only while a press is live. */
  private listen(on: boolean): void {
    const d = this.doc;
    if (on) {
      d.addEventListener("pointermove", this.onMove);
      d.addEventListener("pointerup", this.onUp);
      d.addEventListener("pointercancel", this.onPointerCancel);
      d.addEventListener("keydown", this.onKey);
      d.addEventListener("selectstart", this.onSelect);
      d.addEventListener("dragstart", this.onSelect);
      this.win.addEventListener("blur", this.onBlur);
    } else {
      d.removeEventListener("pointermove", this.onMove);
      d.removeEventListener("pointerup", this.onUp);
      d.removeEventListener("pointercancel", this.onPointerCancel);
      d.removeEventListener("keydown", this.onKey);
      d.removeEventListener("selectstart", this.onSelect);
      d.removeEventListener("dragstart", this.onSelect);
      this.win.removeEventListener("blur", this.onBlur);
    }
  }

  private end(how: DragEnd): void {
    const p = this.press;
    if (p === null) return;
    this.press = null;
    this.listen(false);
    if (!p.dragging) return; // a press below the threshold stays a click (D78-2)
    p.el.removeEventListener("lostpointercapture", this.onLost);
    this.armSwallow(p.el);
    if (how === "release") {
      this.scheduleClear(); // the click follows this pointerup in the same task
    } else {
      // The press goes on without us: the swallow lasts until its pointerup (or the next press).
      this.doc.addEventListener("pointerup", this.onUpAfterCancel, true);
      if (typeof p.el.hasPointerCapture === "function" && p.el.hasPointerCapture(p.pointerId)) {
        try {
          p.el.releasePointerCapture(p.pointerId);
        } catch {
          // Already released.
        }
      }
    }
    this.deps.onEnd?.(p.el, how);
  }

  private armSwallow(el: HTMLElement): void {
    this.clearSwallow();
    this.swallowEl = el;
    this.win.addEventListener("click", this.onClickCapture, true);
  }

  private scheduleClear(): void {
    if (this.swallowTimer !== null) return;
    this.swallowTimer = setTimeout(() => {
      this.swallowTimer = null;
      this.clearSwallow();
    }, 0);
  }

  private clearSwallow(): void {
    if (this.swallowTimer !== null) {
      clearTimeout(this.swallowTimer);
      this.swallowTimer = null;
    }
    if (this.swallowEl === null) return;
    this.swallowEl = null;
    this.win.removeEventListener("click", this.onClickCapture, true);
    this.doc.removeEventListener("pointerup", this.onUpAfterCancel, true);
  }
}
```

```ts
 * W78 (D78-1): the Canvas2D drag label (slice-5 design §4). Canvas2D draws no liquid text, so while
 * an element is dragged, and after a release until its restAlpha is 1, the runtime hides its DOM

 * `color`; screen + forced-colors: none only, so print and forced colours show the text). Same
 * pattern as text-toggle.ts and halo-toggle.ts: one hold per element per instance in `held`,
 * refcounted across instances in stylesheet.ts, written only on change, and a sweep for an element
 * this instance no longer observes. Never under WebGPU (the atlas text rides the liquid there) or
 * reduced motion (drag is ignored). A cancel releases at once through `releaseAwayClass`.
 */
import type { HaloEntry } from "./halo-toggle";
import type { ActiveRenderer } from "./renderers/select";
import { addAwayClass, removeAwayClass } from "./stylesheet";

export interface AwaySyncArgs {
  readonly entries: Iterable<HaloEntry>;
  restAlpha(id: number): number;
  /** The instance's dragged element (`DragTracker.active?.el`), or null. */
  readonly dragged: HTMLElement | null;
  readonly activeRenderer: ActiveRenderer;
  readonly reducedMotion: boolean;
  /** This instance's holds (one per element; refcounted across instances in stylesheet.ts). */
  readonly held: Set<HTMLElement>;
}

/** Dragged, or held since a drag and not yet at rest. NaN counts as at rest (the DOM label shows). */
export function wantsAway(activeRenderer: ActiveRenderer, reducedMotion: boolean, dragged: boolean, held: boolean, restAlpha: number): boolean {
  if (activeRenderer !== "canvas2d" || reducedMotion) return false;
  return dragged || (held && restAlpha < 1);
}

/** Elements visited by the current sync; reused (the sync is synchronous and never re-entered). */
const seen = new Set<HTMLElement>();

export function syncAwayClasses(a: AwaySyncArgs): void {
  seen.clear();
  for (const { id, el } of a.entries) {
    seen.add(el);
    const held = a.held.has(el);
    const want = wantsAway(a.activeRenderer, a.reducedMotion, el === a.dragged, held, a.restAlpha(id));
    if (want && !held) {
      a.held.add(el);
      addAwayClass(el);
    } else if (!want && held) {
      a.held.delete(el);
      removeAwayClass(el);
    }
  }
  // An element this instance still holds but no longer observes (a missed release) lets go too (W74's rule).
  for (const el of a.held) {
    if (!seen.has(el)) {
      a.held.delete(el);
      removeAwayClass(el);
    }
  }
  seen.clear();
}

/** Releases every hold of this instance (reduced motion, a failed frame or rebuild, destroy). */
export function clearAwayClasses(held: Set<HTMLElement>): void {
  for (const el of held) removeAwayClass(el);
  held.clear();
}

/** Releases this instance's hold on `el` (a cancel, unobserve); no-op when it holds none. */
export function releaseAwayClass(held: Set<HTMLElement>, el: HTMLElement): void {
  if (held.delete(el)) removeAwayClass(el);
}
```
