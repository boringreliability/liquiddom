Tilt Bowl

Soft-body blob inside a circular bowl. Tilt the device (or use DevTools sensor emulation) — the blob sloshes toward the low edge as gravity follows the orientation.

Gravity: off — click Enable Tilt or use a fixed vector below.

Mobile (iOS 13+): tap Enable Tilt to grant permission, then tilt the phone. Desktop Chrome: open DevTools → ⋮ menu → More tools → Sensors → set Orientation to "Custom" and drag alpha/beta/gamma sliders.

Refer to (window as any).liquid to inspect the live instance in DevTools.
